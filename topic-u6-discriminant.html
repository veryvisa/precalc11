📌 Key points要点

⭐ Must know必须记住
  • D=b2−4ac: D>0 two roots, D=0 one (double) root, D<0 no real roots.D=b2−4ac：D>0 两个根，D=0 一个（重）根，D<0 无实数根。
  • D a perfect square → rational roots → it factors.D 是完全平方数 → 有理根 → 能因式分解。
  • Unknown k: write D in k, set =0, >0 or <0, solve.含 k：用 k 写出 D，令 =0、>0 或 <0，解出 k。

💡 Can a ball thrown at this speed ever reach 25 m? You can answer yes or no with one number — without solving anything.用这个速度抛出的球能达到 25 米高吗？只算一个数就能回答，根本不用解方程。

  1. The discriminant is D=b2−4ac, the part under the root in the quadratic formula. It tells you how many real roots there are before you solve.判别式 D=b2−4ac，就是求根公式里根号下面的部分。不用解方程，就能知道有几个实数根。
  2. D>0: two different real roots (graph crosses the x-axis twice). D=0: two equal real roots, i.e. one root (vertex touches the x-axis). D<0: no real roots (graph misses the x-axis).D>0：两个不相等的实数根（图象与 x 轴有两个交点）。D=0：两个相等的实数根，即一个根（顶点碰到 x 轴）。D<0：没有实数根（图象与 x 轴不相交）。
  3. If D is a perfect square (0,1,4,9,…), the roots are rational and the quadratic factors.若 D 是完全平方数（0,1,4,9,…），根是有理数，方程可以因式分解。
  4. To find k: write D in terms of k, then set D=0, D>0 or D<0 as the question asks, and solve for k.求 k：先用 k 表示 D，再按题意令 D=0、D>0 或 D<0，解出 k。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Put the equation in the form ax2+bx+c=0 (everything on one side), then write a, b, c with their signs. If there is a k, note which letter it lives in.先化成 ax2+bx+c=0（全部移到一边），再写出带符号的 a、b、c。若有 k，看清它在哪个字母里。
  2. 🎯 Asked求什么
    "How many roots" or "which k"? Equal roots → D=0; two different → D>0; none → D<0; "real roots" (at least one) → D≥0.问的是「几个根」还是「k 取什么」？两等根 → D=0；两不等根 → D>0；无实根 → D<0；「有实数根」（至少一个）→ D≥0。
  3. ✏️ Picture it画出来
    The parabola and the x-axis: it crosses twice (D>0), just touches at the vertex (D=0), or misses (D<0).抛物线和 x 轴：交两次（D>0）、顶点刚好碰到（D=0）、碰不到（D<0）。
  4. 🧰 Tool用什么工具
    D=b2−4ac, with brackets around a negative b. With k, write D in terms of k, then solve the equation or inequality.D=b2−4ac，负的 b 要加括号。含 k 时，先用 k 写出 D，再解方程或不等式。
  5. ✅ Check检验
    Put your k back: D=0 should give a perfect square. For an inequality, test one k on each side. If k multiplies x2, make sure k=0.把 k 代回去：D=0 时应得到完全平方式。不等式就在分界点两边各试一个 k。若 k 是 x2 的系数，要保证 k=0。

🔍 Common mistakes常见错误

Someone made each of these. Tap the line where it first goes wrong.每道题都有人这样做过。点出第一处出错的那一行。

1Calling a zero discriminant no solution把判别式为零当成无解
State the nature of the roots of x2−10x+25=0.判断 x2−10x+25=0 的根的情况。

🧠 "Zero" sounds like "nothing". But 0​=0, so ±D​ gives the same number twice: one repeated root.「零」听起来像「没有」。但 0​=0，所以 ±D​ 两次得到同一个数：一个重根。

🔧 D=0: two equal real roots. In fact (x−5)2=0, so x=5.D=0：两个相等的实数根。也就是 (x−5)2=0，x=5。

✔ Two equal real roots (x=5)两个相等的实数根（x=5）

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q1 B, Practice练习 2

2Losing the sign when squaring a negative b负的 b 平方时丢了符号
State the nature of the roots of 2x2−6x+3=0.判断 2x2−6x+3=0 的根的情况。

🧠 Without brackets, −62 means −(62)=−36. The whole b=−6 must be squared: (−6)2=36. A square is never negative.不加括号时 −62 表示 −(62)=−36。要把整个 b=−6 平方：(−6)2=36。平方永远不会是负数。

🔧 D=36−24=12>0: two different real roots (irrational, since 12 is not a perfect square).D=36−24=12>0：两个不相等的实数根（是无理数，因为 12 不是完全平方数）。

✔ Two different real (irrational) roots两个不相等的实数根（无理数）

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q1 D

3Using only part of the bracket as b只把括号的一部分当成 b
Find k so that x2+(k+1)x+9=0 has two equal real roots.求 k，使 x2+(k+1)x+9=0 有两个相等的实数根。

🧠 b is everything in front of x, so b=k+1. Squaring only k gives a different equation.b 是 x 前面的全部，所以 b=k+1。只平方 k 就成了另一个方程。

🔧 D=(k+1)2−36=0⇒k+1=±6⇒k=5 or k=−7.D=(k+1)2−36=0⇒k+1=±6⇒k=5 或 k=−7。

✔ k=5 or k=−7k=5 或 k=−7

4Forgetting that a cannot be zero忘了 a 不能为零
For which k does kx2+4x+1=0 have two different real roots?k 取何值时，kx2+4x+1=0 有两个不相等的实数根？

🧠 k=0 is less than 4, but then the equation is 4x+1=0, which is linear and has only one root.k=0 也小于 4，但这时方程是 4x+1=0，是一次方程，只有一个根。

🔧 Keep D>0 and add k=0: k<4 and k=0.保留 D>0，再加上 k=0：k<4 且 k=0。

✔ k<4 and k=0k<4 且 k=0

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q2 A

5Not flipping the inequality for a negative除以负数时没有变号
For which k does x2+6x+k=0 have no real roots?k 取何值时，x2+6x+k=0 没有实数根？

🧠 Dividing both sides by −4 reverses the inequality. A quick test shows it: k=0 gives D=36>0, two roots, so k<9 cannot be right.两边除以 −4，不等号要反向。试一下就知道：k=0 时 D=36>0，有两个根，所以 k<9 不可能对。

🔧 −4k<−36⇒k>9. Test k=10: D=36−40=−4<0 ✓.−4k<−36⇒k>9。试 k=10：D=36−40=−4<0 ✓。

✔ k>9

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q2 C

⚠️ Quick list速查

  • Using b=k instead of b=k−2 in x2+(k−2)x+4. The whole bracket is b, so square the whole bracket.在 x2+(k−2)x+4 中把 b 当成 k。整个括号才是 b，要把整个括号平方。
  • Saying "D=0 means no solution". D=0 means exactly one (repeated) root; only D<0 means no real roots.说「D=0 无解」。D=0 是恰好一个（重）根，只有 D<0 才没有实数根。
  • Forgetting a=0: in kx2+6x+1=0, k=0 makes it linear, so it cannot have two roots.忘了 a=0：kx2+6x+1=0 中若 k=0 就成了一次方程，不可能有两个根。

Set 0.02x2−1.2x+25=−0.4x+c and move everything to one side.令 0.02x2−1.2x+25=−0.4x+c，全部移到一边。
(a) c=17, touching at (20,9). (b) For c<17 the line lies below the slope and never meets it.(a) c=17，相切点 (20,9)。(b) c<17 时绳线在雪道下方，两者没有公共点。
  1. 0.02x2−0.8x+(25−c)=0, so D=0.64−0.08(25−c).0.02x2−0.8x+(25−c)=0，所以 D=0.64−0.08(25−c)。
  2. D=0⇒25−c=8⇒c=17. Then 0.02x2−0.8x+8=0⇒(x−20)2=0, so x=20 and y=−0.4(20)+17=9.D=0⇒25−c=8⇒c=17。此时 0.02x2−0.8x+8=0⇒(x−20)2=0，x=20，y=−0.4(20)+17=9。
  3. (b) D increases with c, so c<17 gives D<0: no intersection. The rope line passes below the slope and never touches it.(b) D 随 c 增大而增大，所以 c<17 时 D<0，无交点：绳线从雪道下方经过，碰不到雪道。

💡 Key idea解题思路
Common points satisfy slope = line, which gives a quadratic in x with c inside; exactly one point means D=0.公共点满足「雪道 = 直线」，得到含 c 的二次方程；恰有一个公共点即 D=0。
🔀 Other ways to think不同的思考方式
  • Discriminant: set the two heights equal, then D=0 gives c=17.判别式：令两个高度相等，再令 D=0 得 c=17。
  • Vertex: 0.02x2−0.8x+25−c=0 has a double root exactly when c equals the minimum of 0.02x2−0.8x+25, which is 17 at x=20.顶点法：0.02x2−0.8x+25−c=0 有重根，恰好当 c 等于 0.02x2−0.8x+25 的最小值，即 x=20 时的 17。
