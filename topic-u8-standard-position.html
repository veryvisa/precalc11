📌 Key points要点

⭐ Must know必须记住
  • Start on the positive x-axis; counterclockwise is +, clockwise is −.从 x 轴正半轴出发；逆时针为正，顺时针为负。
  • Reference angle: acute angle to the x-axis. QII 180∘−θ, QIII θ−180∘, QIV 360∘−θ.参考角：终边与 x 轴所成锐角。第二象限 180∘−θ，第三 θ−180∘，第四 360∘−θ。
  • Coterminal: θ±360∘n.终边相同的角：θ±360∘n。

💡 A Ferris wheel seat keeps turning past 90°, past 180°, all the way round and again. To describe angles like 210° or 600° you need one fixed starting line — standard position.摩天轮的座位转过 90°、转过 180°，转完一圈还接着转。要描述 210°、600° 这样的角，需要一条固定的起始边——这就是标准位置。

  1. Standard position: vertex at the origin, initial arm on the positive x-axis. Counterclockwise rotation is positive, clockwise is negative. Where the rotation stops is the terminal arm.标准位置：顶点在原点，始边在 x 轴正半轴。逆时针旋转为正角，顺时针为负角。旋转停下的那条边叫终边。
  2. The reference angle is the acute angle between the terminal arm and the x-axis (never the y-axis). Q I: θ; Q II: 180∘−θ; Q III: θ−180∘; Q IV: 360∘−θ.参考角是终边与 x 轴（不是 y 轴）所夹的锐角。第一象限：θ；第二象限：180∘−θ；第三象限：θ−180∘；第四象限：360∘−θ。
  3. Coterminal angles share a terminal arm: add or subtract 360∘ any number of times, θ+360∘n.终边相同的角（同终边角）：加或减任意次 360∘，即 θ+360∘n。

θcoterminal​=θ+360∘n, n∈Z
Coterminal angles同终边角
θR​=180∘−θ,  θ−180∘,  360∘−θ

🎯 Test tip考试提示
Always draw a 3-second sketch: axes, terminal arm, and a little arc to the x-axis. Almost every reference-angle error comes from skipping the sketch.每次都花 3 秒画草图：坐标轴、终边、一小段到 x 轴的弧。参考角出错几乎都是因为没画图。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Read the angle and its sign: positive turns counterclockwise, negative turns clockwise. Is it bigger than 360∘ or below 0∘?读出这个角和它的符号：正角逆时针转，负角顺时针转。它大于 360∘ 吗？小于 0∘ 吗？
  2. 🎯 Asked求什么
    What is wanted: the quadrant, the reference angle (acute, measured to the x-axis), or coterminal angles? All answers in degrees.要求的是什么：所在象限、参考角（锐角，量到 x 轴），还是同终边角？答案都用度。
  3. ✏️ Picture it画出来
    A 3-second sketch: axes marked 90∘, 180∘, 270∘, 360∘, the terminal arm, and a small arc from the arm to the x-axis.花 3 秒画草图：坐标轴上标出 90∘、180∘、270∘、360∘，画出终边，再画一小段从终边到 x 轴的弧。
  4. 🧰 Tool用什么工具
    First add or subtract 360∘ until the angle is between 0∘ and 360∘. Then find the quadrant, then use that quadrant's rule: θ, 180∘−θ, θ−180∘ or 360∘−θ.先加或减 360∘，直到角落在 0∘ 到 360∘ 之间；再定象限；最后用该象限的公式：θ、180∘−θ、θ−180∘ 或 360∘−θ。
  5. ✅ Check检验
    The reference angle must be between 0∘ and 90∘ and match the sketch. Two angles are coterminal only if their difference is a multiple of 360∘.参考角必须在 0∘ 到 90∘ 之间，并且和草图对得上。两个角只有在差是 360∘ 的整数倍时才同终边。

1Reading a graph: points, intercepts, slope读图：点、截距、斜率
In which quadrant is the point (−3,−5)?点 (−3,−5) 在第几象限？

🩹 5-minute repair5 分钟补一补 · Reading a graph: points, intercepts, slope读图：点、截距、斜率 (Grade年级 9–10)
A point is (x,y): across first, then up. x-intercepts are where y=0 (the graph crosses the horizontal axis); the y-intercept is where x=0. Slope =runrise​=x2​−x1​y2​−y1​​.点写作 (x,y)：先横后纵。x 截距是 y=0 的地方（图象穿过横轴处）；y 截距是 x=0 的地方。斜率 =横向变化纵向变化​=x2​−x1​y2​−y1​​。
  1. For y=x2−4: y-intercept at x=0 is −4; x-intercepts solve x2−4=0: x=±2.y=x2−4：令 x=0 得 y 截距 −4；令 y=0 解 x2−4=0 得 x 截距 x=±2。
  2. Above the x-axis means y>0; below means y<0.在 x 轴上方表示 y>0；下方表示 y<0。
Try one:试一道：
Where does y=2x−6 cross the x-axis?y=2x−6 与 x 轴交于哪里？

2Negative numbers: add, subtract, multiply负数的加减乘
Work out −480+360.计算 −480+360。

🩹 5-minute repair5 分钟补一补 · Negative numbers: add, subtract, multiply负数的加减乘 (Grade年级 7–9)
Subtracting a negative is adding: 5−(−3)=5+3=8. Same signs multiply to +, different signs to −. Squaring a negative is positive: (−4)2=16, but −42=−16 (the square happens first).减去负数等于加上它：5−(−3)=5+3=8。同号相乘得正，异号相乘得负。负数的平方是正的：(−4)2=16，但 −42=−16（先算平方）。
  1. −7−(−2): change "minus negative" to "plus": −7+2=−5.−7−(−2)：把「减负」改成「加」：−7+2=−5。
  2. (−3)(−5)=15 (same signs), (−3)(5)=−15 (different signs).(−3)(−5)=15（同号），(−3)(5)=−15（异号）。
  3. Plugging in x=−3 to x2: write brackets first, (−3)2=9.把 x=−3 代入 x2：先加括号，(−3)2=9。
Try one:试一道：
Evaluate b2−4ac when a=2, b=−3, c=−1.当 a=2, b=−3, c=−1 时，求 b2−4ac。

3Solving a linear equation解一元一次方程
Two angles on a straight line add to 180∘. One is 35∘. Solve x+35=180.一条直线上的两个角加起来是 180∘，其中一个是 35∘。解 x+35=180。

🩹 5-minute repair5 分钟补一补 · Solving a linear equation解一元一次方程 (Grade年级 8–9)
Do the same thing to both sides. Clear brackets, collect x on one side and numbers on the other, then divide. With fractions, multiply every term by the common denominator first.两边做同样的事。先去括号，把含 x 的项移到一边、数字移到另一边，最后除以系数。有分数时先把每一项都乘以公分母。
  1. 3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7.3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7。
  2. 2x​+3x​=5: multiply every term by 6 → 3x+2x=30 → x=6.2x​+3x​=5：每项乘 6 → 3x+2x=30 → x=6。
  3. Check by substituting: 3(7−2)=15 and 7+8=15 ✓.代回检验：3(7−2)=15，7+8=15 ✓。

① Worked example — read it完整例题——看懂
For −600∘, find the coterminal angle between 0∘ and 360∘, the quadrant and the reference angle.对 −600∘，求 0∘ 到 360∘ 之间的同终边角、所在象限和参考角。
  1. 🔎 Given已知
    Negative, so the turn is clockwise, and it is more than one full turn.负角，所以是顺时针转，而且超过了一整圈。
  2. 🧰 Tool用什么工具
    Add 360∘ twice: −600∘+720∘=120∘.加两次 360∘：−600∘+720∘=120∘。
  3. ✏️ Picture it画出来
    120∘ is between 90∘ and 180∘: quadrant II, upper left.120∘ 在 90∘ 和 180∘ 之间：第二象限，左上方。
  4. 🧰 Tool用什么工具
    Quadrant II rule: 180∘−120∘=60∘.第二象限公式：180∘−120∘=60∘。
  5. ✅ Check检验
    60∘ is acute ✓, and 120∘−(−600∘)=720∘=2×360∘ ✓.60∘ 是锐角 ✓；120∘−(−600∘)=720∘=2×360∘ ✓。
✔

🔍 Common mistakes常见错误

Someone made each of these. Tap the line where it first goes wrong.每道题都有人这样做过。点出第一处出错的那一行。

1Measuring the reference angle to the y-axis把参考角量到了 y 轴
Find the reference angle of 240∘.求 240∘ 的参考角。

🧠 The arm looks closer to the y-axis, so it feels natural to measure there. But a reference angle is always measured to the x-axis.终边看起来离 y 轴更近，所以很自然就量到那里去了。但参考角永远量到 x 轴。

🔧 Measure back to the negative x-axis at 180∘: 240∘−180∘=60∘.量回到 x 轴负半轴（180∘）：240∘−180∘=60∘。

✔ 60∘

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q1 A

2Using another quadrant's rule用错了象限的公式
Find the reference angle of 320∘.求 320∘ 的参考角。

🧠 The rules were learned as a list, and the wrong line of the list was picked without a sketch. 140∘ is not even acute, which is a warning sign.公式是当成一张表背下来的，没画草图就挑错了一行。140∘ 连锐角都不是，这本身就是警报。

🔧 Quadrant IV is 360∘−θ: 360∘−320∘=40∘.第四象限用 360∘−θ：360∘−320∘=40∘。

✔ 40∘

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q1 C, Check-up测评 Q2 B

3Thinking a negative angle shares the arm of the positive one以为负角和对应的正角终边相同
Give the angle between 0∘ and 360∘ that is coterminal with −70∘.写出 0∘ 到 360∘ 之间与 −70∘ 终边相同的角。

🧠 The minus sign is a direction, not decoration. −70∘ turns clockwise into quadrant IV; 70∘ turns the other way into quadrant I.负号表示方向，不是装饰。−70∘ 顺时针转到第四象限；70∘ 逆时针转到第一象限。

🔧 Add a full turn: −70∘+360∘=290∘.加一整圈：−70∘+360∘=290∘。

✔ 290∘

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q2 A

4Turning a negative angle the wrong way负角转错了方向
State the quadrant and reference angle of −120∘.写出 −120∘ 所在象限和参考角。

🧠 The quadrant was read as if the angle turned counterclockwise. Clockwise, −90∘ is straight down and −180∘ is the negative x-axis, so −120∘ lands in quadrant III.把它当成逆时针转来读象限了。顺时针转时，−90∘ 指向正下方，−180∘ 是 x 轴负半轴，所以 −120∘ 落在第三象限。

🔧 −120∘+360∘=240∘: quadrant III, reference angle 240∘−180∘=60∘. (The 60∘ happened to be right; the quadrant was not.)−120∘+360∘=240∘：第三象限，参考角 240∘−180∘=60∘。（60∘ 碰巧对了，象限却错了。）

✔ Quadrant III, 60∘第三象限，60∘

5Taking off only one full turn只减了一整圈
For 820∘, find the quadrant and the reference angle.对 820∘，求所在象限和参考角。

🧠 The first subtraction was fine, but 460∘ is still more than a full turn. The quadrant rules only work between 0∘ and 360∘; a 280∘ "reference angle" is the giveaway.第一步减法没错，但 460∘ 仍然超过一整圈。象限公式只在 0∘ 到 360∘ 之间才能用；算出 280∘ 的「参考角」就露馅了。

🔧 Take off another turn: 460∘−360∘=100∘, quadrant II, reference angle 180∘−100∘=80∘.再减一圈：460∘−360∘=100∘，第二象限，参考角 180∘−100∘=80∘。

✔ Quadrant II, 80∘第二象限，80∘

⚠️ Quick list速查

  • Measuring the reference angle to the y-axis. For 120∘ the reference angle is 60∘ (to the x-axis), not 30∘.把参考角量到 y 轴。120∘ 的参考角是 60∘（量到 x 轴），不是 30∘。
  • Using 180∘−θ in every quadrant. Sketch first, then pick the rule for that quadrant.每个象限都用 180∘−θ。先画草图，再按所在象限选公式。
  • Thinking −60∘ is coterminal with 60∘. Negative goes clockwise: −60∘ is coterminal with 300∘.以为 −60∘ 与 60∘ 终边相同。负角顺时针转：−60∘ 与 300∘ 终边相同。
