📌 Key points要点

⭐ Must know必须记住
  • SSA (∠A, a, b): height h=bsinA.SSA（∠A、a、b）：高 h=bsinA。
  • Acute A: a<h none; a=h one; h<a<b TWO; a≥b one.A 为锐角：a<h 无；a=h 一个；h<a<b 两个；a≥b 一个。
  • Two triangles: B2​=180∘−B1​; finish each triangle separately.两个三角形：B2​=180∘−B1​；两个三角形分别解完。

💡 Give someone an angle, the side next to it, and a swinging side opposite it. That swinging side might miss, touch once, or hit the base in TWO places — so the same data can build 0, 1 or 2 different triangles.给你一个角、它旁边的一条边，再给一条能摆动的对边。这条边可能够不着底边、刚好碰到一次，或者在「两个」地方碰到——同样的条件能画出 0 个、1 个或 2 个不同的三角形。

  1. The ambiguous case is SSA: you know ∠A, its opposite side a, and another side b. Compute the height h=bsinA — the shortest distance the swinging side a must reach.两解情形就是 SSA：已知 ∠A、它的对边 a 和另一边 b。先算高 h=bsinA——摆动边 a 至少要这么长才够得着。
  2. If ∠A is acute: a<h → no triangle; a=h → one right triangle; h<a<b → TWO triangles; a≥b → one triangle.若 ∠A 为锐角：a<h → 无三角形；a=h → 一个直角三角形；h<a<b → 两个三角形；a≥b → 一个三角形。
  3. If ∠A is obtuse: a>b → one triangle; a≤b → none.若 ∠A 为钝角：a>b → 一个三角形；a≤b → 无三角形。
  4. When there are two triangles, the sine law gives B1​; the second is B2​=180∘−B1​ (same sine). Finish each triangle separately.有两个三角形时，正弦定理先给出 B1​；另一个是 B2​=180∘−B1​（正弦值相同）。两个三角形分别解完。

🎯 Test tip考试提示
Every SSA question: compute h=bsinA first and write the comparison ("h<a<b, so two triangles"). Teachers mark the classification separately — and it tells you whether to look for a second answer.每道 SSA 题都先算 h=bsinA，并写出比较（「h<a<b，所以有两个三角形」）。老师会单独给分类分——它也告诉你要不要找第二个解。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Label the known angle A, the side across from it a, and the other known side b (it touches A). Is A acute or obtuse?标出已知角 A、它的对边 a、另一条已知边 b（它挨着 A）。A 是锐角还是钝角？
  2. 🎯 Asked求什么
    How many triangles (0, 1 or 2)? If asked to solve, every missing angle and side for EACH triangle, rounded as stated.有几个三角形（0、1 或 2）？如果要求解，每个三角形的所有未知角和边都要求出，按要求取近似。
  3. ✏️ Picture it画出来
    Draw A with side b to C, drop the height h from C, then swing side a from C like a gate and count where it hits the base.画出角 A 和边 b 到 C，从 C 作高 h，再把边 a 从 C 像门一样摆下来，数它碰到底边几次。
  4. 🧰 Tool用什么工具
    h=bsinA. Acute A: a<h none, a=h one (right), h<a<b two, a≥b one. Then sinB=absinA​ and B2​=180∘−B1​.h=bsinA。A 为锐角时：a<h 无解，a=h 一解（直角），h<a<b 两解，a≥b 一解。再用 sinB=absinA​，B2​=180∘−B1​。
  5. ✅ Check检验
    For each triangle: angles add to 180∘, and the longest side faces the largest angle. B2​ only counts if A+B2​<180∘.每个三角形：三角之和 180∘，最长边对最大角。只有 A+B2​<180∘ 时 B2​ 才算数。

3Rearranging a formula公式变形（求某个字母）
Solve sinAa​=sinBb​ for sinB.由 sinAa​=sinBb​ 解出 sinB。

🩹 5-minute repair5 分钟补一补 · Rearranging a formula公式变形（求某个字母） (Grade年级 9–10)
Treat the other letters as numbers and undo operations in reverse order. A=P(1+r) for r: divide by P, then subtract 1: r=PA​−1.把其他字母当成数字，按相反顺序撤销运算。由 A=P(1+r) 求 r：先除以 P，再减 1：r=PA​−1。
  1. y=a(x−p)2+q for a: subtract q, divide by (x−p)2: a=(x−p)2y−q​.由 y=a(x−p)2+q 求 a：减 q，再除以 (x−p)2：a=(x−p)2y−q​。
  2. Substitute numbers first if the question gives them — fewer letters, fewer slips.题目给了数字就先代入——字母越少，越不容易错。

4Solving a linear equation解一元一次方程
A triangle has angles 40∘ and 118∘. Find the third angle.三角形有两个角是 40∘ 和 118∘，求第三个角。

🩹 5-minute repair5 分钟补一补 · Solving a linear equation解一元一次方程 (Grade年级 8–9)
Do the same thing to both sides. Clear brackets, collect x on one side and numbers on the other, then divide. With fractions, multiply every term by the common denominator first.两边做同样的事。先去括号，把含 x 的项移到一边、数字移到另一边，最后除以系数。有分数时先把每一项都乘以公分母。
  1. 3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7.3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7。
  2. 2x​+3x​=5: multiply every term by 6 → 3x+2x=30 → x=6.2x​+3x​=5：每项乘 6 → 3x+2x=30 → x=6。
  3. Check by substituting: 3(7−2)=15 and 7+8=15 ✓.代回检验：3(7−2)=15，7+8=15 ✓。

  • Stopping at B1​ from the calculator and missing the second triangle. In SSA, always test 180∘−B1​.只用计算器得出的 B1​，漏掉第二个三角形。SSA 一定要检验 180∘−B1​。
