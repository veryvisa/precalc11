📌 Key points要点

⭐ Must know必须记住
  • Solve like an equation; multiply or divide by a NEGATIVE → flip the sign.像解方程一样解；乘或除以负数 → 不等号反向。
  • ≤,≥: closed dot, square bracket. <,>: open dot, round bracket. ∞ always round.≤,≥：实心点、方括号。<,>：空心点、圆括号。∞ 永远用圆括号。
  • Double inequality: do the same step to all three parts.连写不等式：每一步对三部分同时做。

💡 A taxi charges a flag fee plus a price per km, and you have 30 dollars. The answer is not one distance — it is every distance up to a limit. That is an inequality.出租车收起步价加每公里费用，你只有 30 加元。答案不是一个距离，而是某个上限以内的所有距离——这就是不等式。

  1. Solve like an equation: same thing to both sides. One extra rule: multiplying or dividing by a NEGATIVE number flips the sign (< becomes >).像解方程一样，两边做同样的运算。只多一条规则：两边乘或除以一个负数，不等号要反向（< 变 >）。
  2. Three ways to write the answer x≤4: interval (−∞,4]; set {x∣x≤4, x∈R}; number line with a closed dot at 4 and shading to the left.x≤4 有三种写法：区间 (−∞,4]；集合 {x∣x≤4, x∈R}；数轴上 4 处画实心点，向左涂。
  3. Square bracket / closed dot = included (≤, ≥). Round bracket / open dot = not included (<, >). Infinity always gets a round bracket.方括号/实心点 = 包含（≤、≥）；圆括号/空心点 = 不包含（<、>）。无穷大永远用圆括号。

a<b and k<0 ⇒ ka>kb

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Where are the x terms? Are there brackets or fractions? Is the sign strict (<, >) or does it include the endpoint (≤, ≥)?x 项在哪边？有没有括号或分数？不等号是严格的（<、>），还是包含端点（≤、≥）？
  2. 🎯 Asked求什么
    Every x that makes it true: a whole set of numbers, written in interval notation, set notation or on a number line.让它成立的所有 x：是一整组数，用区间记号、集合记号或数轴表示。
  3. ✏️ Picture it画出来
    A number line with the boundary number, an open or closed dot, and shading on one side.一条数轴：标出分界点，画空心点或实心点，再涂一侧。
  4. 🧰 Tool用什么工具
    Solve it like an equation. Flip the sign ONLY when you multiply or divide by a negative, or move x to the side where its coefficient is positive.像解方程一样解。「只有」乘或除以负数时才变号；也可以把 x 移到系数为正的一边。
  5. ✅ Check检验
    Test one number inside your answer and one outside in the ORIGINAL. For ≤ or ≥, the boundary must work too.在答案里外各取一个数，代回「原」不等式。≤ 或 ≥ 时，分界点本身也要成立。

1Solving a linear equation解一元一次方程
Solve 5x−3=12.解 5x−3=12。

🩹 5-minute repair5 分钟补一补 · Solving a linear equation解一元一次方程 (Grade年级 8–9)
Do the same thing to both sides. Clear brackets, collect x on one side and numbers on the other, then divide. With fractions, multiply every term by the common denominator first.两边做同样的事。先去括号，把含 x 的项移到一边、数字移到另一边，最后除以系数。有分数时先把每一项都乘以公分母。
  1. 3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7.3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7。
  2. 2x​+3x​=5: multiply every term by 6 → 3x+2x=30 → x=6.2x​+3x​=5：每项乘 6 → 3x+2x=30 → x=6。
  3. Check by substituting: 3(7−2)=15 and 7+8=15 ✓.代回检验：3(7−2)=15，7+8=15 ✓。
Try one:试一道：
Solve 4x−1​=6x​.解 4x−1​=6x​。

2Negative numbers: add, subtract, multiply负数的加减乘
Which statement is true?下面哪个式子成立？

🩹 5-minute repair5 分钟补一补 · Negative numbers: add, subtract, multiply负数的加减乘 (Grade年级 7–9)
Subtracting a negative is adding: 5−(−3)=5+3=8. Same signs multiply to +, different signs to −. Squaring a negative is positive: (−4)2=16, but −42=−16 (the square happens first).减去负数等于加上它：5−(−3)=5+3=8。同号相乘得正，异号相乘得负。负数的平方是正的：(−4)2=16，但 −42=−16（先算平方）。
  1. −7−(−2): change "minus negative" to "plus": −7+2=−5.−7−(−2)：把「减负」改成「加」：−7+2=−5。
  2. (−3)(−5)=15 (same signs), (−3)(5)=−15 (different signs).(−3)(−5)=15（同号），(−3)(5)=−15（异号）。
  3. Plugging in x=−3 to x2: write brackets first, (−3)2=9.把 x=−3 代入 x2：先加括号，(−3)2=9。
Try one:试一道：
Evaluate b2−4ac when a=2, b=−3, c=−1.当 a=2, b=−3, c=−1 时，求 b2−4ac。

3Inequalities: when the sign flips不等式：什么时候变号
Start with 3<5 and multiply both sides by −2. Which statement is true?从 3<5 出发，两边都乘 −2。哪个式子成立？

🩹 5-minute repair5 分钟补一补 · Inequalities: when the sign flips不等式：什么时候变号 (Grade年级 9)
Solve like an equation, EXCEPT: multiplying or dividing both sides by a negative number flips the sign. −2x>6 → x<−3. Test a number to be sure: x=−4 gives 8>6 ✓.像解方程一样解，唯一例外：两边同乘或同除以负数，不等号要反向。−2x>6 → x<−3。代一个数确认：x=−4 得 8>6 ✓。
  1. 5−3x≤11 → −3x≤6 → x≥−2 (divided by −3: flip).5−3x≤11 → −3x≤6 → x≥−2（除以 −3：变号）。
  2. Number line: closed dot for ≤,≥; open dot for <,>.数轴：≤,≥ 用实心点；<,> 用空心点。

Solve 4−2x<10.解 4−2x<10。

4Distributing (and the minus sign)去括号（尤其是负号）
Expand −3(x−4).展开 −3(x−4)。

🩹 5-minute repair5 分钟补一补 · Distributing (and the minus sign)去括号（尤其是负号） (Grade年级 8–9)
Multiply EVERY term inside the bracket: 3(x−4)=3x−12. A minus in front changes every sign inside: −(x−5)=−x+5, and 2−(x+3)=2−x−3=−x−1.括号里的每一项都要乘到：3(x−4)=3x−12。前面是负号时，括号里每一项都变号：−(x−5)=−x+5，2−(x+3)=2−x−3=−x−1。
  1. −2(3x−1)=−6x+2 (the −1 becomes +2).−2(3x−1)=−6x+2（−1 变成 +2）。
  2. x(x+2)−3(x+2)=x2+2x−3x−6=x2−x−6.x(x+2)−3(x+2)=x2+2x−3x−6=x2−x−6。
Try one:试一道：
Expand and simplify 4x−(2x−7).去括号并化简 4x−(2x−7)。

5Lowest common denominator最简公分母
What is the lowest common denominator of 4x​ and 6x​?4x​ 和 6x​ 的最小公分母是多少？

🩹 5-minute repair5 分钟补一补 · Lowest common denominator最简公分母 (Grade年级 8–10)
Factor each denominator; the LCD uses every factor the HIGHEST number of times it appears. For 6 and 4: 2⋅3 and 22 → 22⋅3=12. For x and x2: x2. For (x+1) and (x−2): (x+1)(x−2).把每个分母分解；最简公分母取每个因式出现的最高次数。6 和 4：2⋅3 与 22 → 22⋅3=12。x 和 x2：x2。(x+1) 和 (x−2)：(x+1)(x−2)。
  1. 2x1​ and 3x21​: LCD =6x2.2x1​ 与 3x21​：最简公分母 =6x2。
  2. Multiply top AND bottom by what is missing: 2x1​=6x23x​.分子分母同乘缺的部分：2x1​=6x23x​。
Try one:试一道：

🔍 Common mistakes常见错误

Someone made each of these. Tap the line where it first goes wrong.每道题都有人这样做过。点出第一处出错的那一行。

1Not flipping when dividing by a negative除以负数时没有变号
Solve 5−4x>17.解 5−4x>17。

🧠 It was treated exactly like an equation. Dividing by −4 swaps the order of numbers, so the sign must turn around.完全当成方程来解了。除以 −4 会把数的大小顺序倒过来，所以不等号要反向。

🔧 x<−3. Test x=−4: 5+16=21>17 ✓.x<−3。检验 x=−4：5+16=21>17 ✓。

✔ x<−3

2Flipping because the number is negative因为数是负的就变号
Solve 3x+5<−7.解 3x+5<−7。

🧠 The −12 looked like a reason to flip. What matters is the number you divide BY: here it is +3, so the sign stays.看到 −12 就以为要变号。关键是你「除以」的那个数：这里是 +3，不等号不变。

🔧 x<−4. Test x=−5: −15+5=−10<−7 ✓.x<−4。检验 x=−5：−15+5=−10<−7 ✓。

✔ x<−4

3Multiplying the minus sign into only the first term负号只乘了括号里的第一项
Solve 10−2(x−3)≤4.解 10−2(x−3)≤4。

🧠 The −2 multiplies BOTH terms in the bracket: −2×(−3)=+6.−2 要乘括号里的「两项」：−2×(−3)=+6。

🔧 10−2x+6≤4, −2x≤−12, so x≥6.10−2x+6≤4，−2x≤−12，所以 x≥6。

✔ x≥6

4Using a square bracket at infinity无穷大用了方括号
Solve 2x−1≥11 and write the answer in interval notation.解 2x−1≥11，用区间记号写出答案。

🧠 Both ends got the same bracket. Infinity is not a number you can reach, so it can never be included.两端用了一样的括号。无穷大不是能到达的数，永远不能被包含。

🔧 [6,∞): square at 6 (included), round at ∞.[6,∞)：6 处用方括号（包含），∞ 处用圆括号。

✔ [6,∞)

5Leaving the brackets at their old ends after a flip变号后括号还留在原来的一端
Solve −7≤1−2x<5 and write the answer in interval notation.解 −7≤1−2x<5，用区间记号写出答案。

🧠 The square bracket stayed on the left, where the ≤ used to be. After the flip, the "or equal" belongs to 4, not to −2.方括号还留在左边，也就是原来 ≤ 的位置。变号以后，「等于」跟着的是 4，不是 −2。

🔧 Rewrite from small to large: −2<x≤4, so (−2,4].按从小到大重写：−2<x≤4，即 (−2,4]。

✔ (−2,4]

⚠️ Quick list速查

  • Forgetting to flip when dividing by a negative: −3x<12 gives x>−4, not x<−4. Test a number to be sure.除以负数忘了变号：−3x<12 得 x>−4，不是 x<−4。代一个数检验一下。
  • Writing [−∞,4] or (−∞,4) for x≤4. Infinity is never included; 4 is included, so (−∞,4].把 x≤4 写成 [−∞,4] 或 (−∞,4)。无穷大永远不包含，4 要包含，所以是 (−∞,4]。
  • Flipping the sign when you only SUBTRACT a number. Only multiplying or dividing by a negative flips it.只是减去一个数也变号。只有乘或除以负数才变号。
