📌 Key points要点

⭐ Must know必须记住
  • Isolate the ratio first; ∣sinθ∣ or ∣cosθ∣>1 → no solution.先把三角比单独放一边；∣sinθ∣ 或 ∣cosθ∣>1 → 无解。
  • Reference angle from the POSITIVE value; the sign picks two quadrants (CAST).参考角用正值求；符号决定两个象限（CAST）。
  • 0 and ±1 are quadrantal: read them off the unit circle.0 和 ±1 对应轴上角：直接从单位圆读。

💡 Your calculator says sin−1(−0.5)=−30∘ and stops. But between 0∘ and 360∘ there are TWO angles with sinθ=−21​ — and the test wants both.计算器算 sin−1(−0.5)=−30∘ 就停了。可在 0∘ 到 360∘ 之间，有「两个」角满足 sinθ=−21​——考试两个都要。

  1. Step 1: isolate the trig ratio, e.g. 2sinθ+1=0⇒sinθ=−21​. If sin or cos ends up bigger than 1 or less than −1, there is no solution.第一步：把三角比单独留下，如 2sinθ+1=0⇒sinθ=−21​。若 sin 或 cos 大于 1 或小于 −1，无解。
  2. Step 2: reference angle from the POSITIVE value: special triangle if exact, or the inverse key for decimals.第二步：用正值求参考角：特殊值看特殊三角形，小数用反函数键。
  3. Step 3: the sign tells you which two quadrants (CAST). Step 4: build each angle from the reference angle with the quadrant rules.第三步：由符号和 CAST 确定是哪两个象限。第四步：在每个象限里用参考角写出对应的角。
  4. Values of 0, ±1 are quadrantal: read them off the unit circle (sinθ=1⇒θ=90∘ only).0、±1 对应轴上角，直接看单位圆（sinθ=1⇒θ=90∘，只有一个）。

🎯 Test tip考试提示
Write the two quadrants next to the equation before you touch the calculator ("sin < 0 → Q III, Q IV"). Round only the final angles; use the unrounded reference angle in your subtractions.按计算器之前，先在方程旁写下两个象限（如「sin < 0 → 第三、四象限」）。只对最后的角四舍五入；做减法时用未取整的参考角。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    The interval (usually 0∘≤θ<360∘) and the equation. Isolate the ratio: sinθ, cosθ or tanθ equals a number. If sine or cosine is outside [−1,1], stop: no solution.看区间（通常是 0∘≤θ<360∘）和方程。先把三角比分离出来：sinθ、cosθ 或 tanθ 等于一个数。若 sin 或 cos 不在 [−1,1] 内，停：无解。
  2. 🎯 Asked求什么
    ALL the angles in the interval, exact if the value is special, otherwise rounded as asked. Usually two; 0 and ±1 give angles on the axes.区间内的「所有」角：特殊值写精确角，否则按要求取近似。通常有两个；0 和 ±1 对应坐标轴上的角。
  3. ✏️ Picture it画出来
    A quick unit circle: mark where the ratio is positive or negative (CAST), then draw two terminal arms with the same reference angle.画一个简单的单位圆：用 CAST 标出该比值为正或为负的象限，再画两条参考角相同的终边。
  4. 🧰 Tool用什么工具
    Reference angle from the POSITIVE value (special triangle or inverse key). Then Q I: θR​, Q II: 180∘−θR​, Q III: 180∘+θR​, Q IV: 360∘−θR​.用「正值」求参考角（特殊三角形或反三角键）。然后第一象限 θR​，第二象限 180∘−θR​，第三象限 180∘+θR​，第四象限 360∘−θR​。
  5. ✅ Check检验
    Put each angle into the ORIGINAL equation (calculator in degrees). Count them: did you find both?把每个角代回「原」方程（计算器用角度制）。数一数：两个都找到了吗？

1Solving a linear equation解一元一次方程
Solve 3y+2=−4.解 3y+2=−4。

🩹 5-minute repair5 分钟补一补 · Solving a linear equation解一元一次方程 (Grade年级 8–9)
Do the same thing to both sides. Clear brackets, collect x on one side and numbers on the other, then divide. With fractions, multiply every term by the common denominator first.两边做同样的事。先去括号，把含 x 的项移到一边、数字移到另一边，最后除以系数。有分数时先把每一项都乘以公分母。
  1. 3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7.3(x−2)=x+8 → 3x−6=x+8 → 2x=14 → x=7。
  2. 2x​+3x​=5: multiply every term by 6 → 3x+2x=30 → x=6.2x​+3x​=5：每项乘 6 → 3x+2x=30 → x=6。
  3. Check by substituting: 3(7−2)=15 and 7+8=15 ✓.代回检验：3(7−2)=15，7+8=15 ✓。

2Rearranging a formula公式变形（求某个字母）
Solve 2​s+1=0 for s.由 2​s+1=0 解出 s。

🩹 5-minute repair5 分钟补一补 · Rearranging a formula公式变形（求某个字母） (Grade年级 9–10)
Treat the other letters as numbers and undo operations in reverse order. A=P(1+r) for r: divide by P, then subtract 1: r=PA​−1.把其他字母当成数字，按相反顺序撤销运算。由 A=P(1+r) 求 r：先除以 P，再减 1：r=PA​−1。
  1. y=a(x−p)2+q for a: subtract q, divide by (x−p)2: a=(x−p)2y−q​.由 y=a(x−p)2+q 求 a：减 q，再除以 (x−p)2：a=(x−p)2y−q​。
  2. Substitute numbers first if the question gives them — fewer letters, fewer slips.题目给了数字就先代入——字母越少，越不容易错。
Try one:试一道：
The point (1,5) is on y=a(x−3)2−3. Find a.点 (1,5) 在 y=a(x−3)2−3 上，求 a。

4Reading a graph: points, intercepts, slope读图：点、截距、斜率

🩹 5-minute repair5 分钟补一补 · Reading a graph: points, intercepts, slope读图：点、截距、斜率 (Grade年级 9–10)
A point is (x,y): across first, then up. x-intercepts are where y=0 (the graph crosses the horizontal axis); the y-intercept is where x=0. Slope =runrise​=x2​−x1​y2​−y1​​.点写作 (x,y)：先横后纵。x 截距是 y=0 的地方（图象穿过横轴处）；y 截距是 x=0 的地方。斜率 =横向变化纵向变化​=x2​−x1​y2​−y1​​。

  2. Above the x-axis means y>0; below means y<0.在 x 轴上方表示 y>0；下方表示 y<0。

1Stopping at the calculator answer停在计算器给的答案上
Solve sinθ=0.6 for 0∘≤θ<360∘, to the nearest tenth.解 sinθ=0.6，0∘≤θ<360∘，精确到 0.1°。

🧠 The inverse key returns ONE angle. Sine is positive in Q II as well, so a second angle has the same sine.反三角键只给「一个」角。sin 在第二象限也为正，所以还有一个角的 sin 相同。

🔧 Q II: 180∘−36.87∘=143.13∘. Answers: 36.9∘ and 143.1∘.第二象限：180∘−36.87∘=143.13∘。答案：36.9∘ 和 143.1∘。

✔ θ≈36.9∘, 143.1∘

2Taking the reference angle from the negative value用负值求参考角
Solve cosθ=−0.4 for 0∘≤θ<360∘, to the nearest tenth.解 cosθ=−0.4，0∘≤θ<360∘，精确到 0.1°。

🧠 A reference angle is always between 0∘ and 90∘. Using the negative value gives an angle already in Q II, and the quadrant rules then move it twice.参考角永远在 0∘ 到 90∘ 之间。用负值求出的角本身已在第二象限，再套象限公式就挪了两次。

🔧 θR​=cos−10.4≈66.42∘. Q II: 113.6∘; Q III: 246.4∘.θR​=cos−10.4≈66.42∘。第二象限：113.6∘；第三象限：246.4∘。

✔ θ≈113.6∘, 246.4∘

3Choosing the wrong pair of quadrants象限选错了
Solve tanθ=−1 for 0∘≤θ<360∘.解 tanθ=−1，0∘≤θ<360∘。

🧠 In Q III both x and y are negative, so tan=xy​ is positive (the T in CAST). Tangent is negative in Q II and Q IV.第三象限 x、y 都为负，所以 tan=xy​ 为正（CAST 里的 T）。tan 在第二、四象限为负。

🔧 Q II: 180∘−45∘=135∘; Q IV: 360∘−45∘=315∘.第二象限：180∘−45∘=135∘；第四象限：360∘−45∘=315∘。

✔ θ=135∘, 315∘

🔗 The same mistake is a wrong option in:同一个错误也是这些题的错误选项： Check-up测评 Q2 C

4Dividing before moving the constant还没移项就先除
Solve 2cosθ−1=0 for 0∘≤θ<360∘.解 2cosθ−1=0，0∘≤θ<360∘。

🧠 Dividing by 2 must divide EVERY term: 22cosθ−1​=cosθ−21​. Moving the constant first avoids the trap.除以 2 要除「每一项」：22cosθ−1​=cosθ−21​。先移常数项就不会掉进这个坑。

🔧 2cosθ=1, cosθ=21​, θR​=60∘; cosine positive in Q I and Q IV: 60∘, 300∘.2cosθ=1，cosθ=21​，θR​=60∘；cos 在第一、四象限为正：60∘，300∘。

✔ θ=60∘, 300∘

5Missing that the value is out of range没发现比值超出范围
Solve 4sinθ+7=2 for 0∘≤θ<360∘.解 4sinθ+7=2，0∘≤θ<360∘。

🧠 Dividing by 4 gives −45​, not −54​. The flipped fraction looked "normal", so the impossible value was never noticed.除以 4 得 −45​，不是 −54​。分数倒过来后看着很「正常」，于是没发现这是个不可能的值。

🔧 sinθ=−1.25<−1. Sine is never below −1: no solution.sinθ=−1.25<−1。sin 不会小于 −1：无解。

✔ No solution无解

  • Stopping at the calculator answer. Inverse keys give one angle, but in 0∘–360∘ every tangent value, and every sine or cosine value strictly between −1 and 1, has two answers.停在计算器给的答案上。反函数键只给一个角；而在 0∘–360∘ 内，任何 tan 值、以及严格介于 −1 和 1 之间的 sin、cos 值都有两个解。
