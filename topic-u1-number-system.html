📌 Key points要点

⭐ Must know必须记住
  • N⊂W⊂I⊂Q⊂R; 0 is whole but not natural.N⊂W⊂I⊂Q⊂R；0 是非负整数（W），但不是自然数。
  • Rational = ba​ with integers a,b: decimal ends or repeats. Irrational: never ends, never repeats.有理数＝两个整数之比 ba​，小数会终止或循环；无理数的小数不终止也不循环。
  • Simplify before classifying: 49​=7, 3−8​=−2; −4​ is not real.先化简再分类：49​=7，3−8​=−2；−4​ 不是实数。

💡 Is 49​ the same kind of number as 50​? One is exactly 7; the other has decimals that never end and never repeat — and that difference decides how you can work with it.49​ 和 50​ 是同一类数吗？前者正好是 7，后者的小数既不终止也不循环——这个区别决定了你能怎样处理它。

  1. The families nest inside each other: natural N={1,2,3,…} ⊂ whole W={0,1,2,…} ⊂ integers I ⊂ rational Q ⊂ real R. A number belongs to every family that contains its smallest family.数的家族一层套一层：自然数 N={1,2,3,…} ⊂ 整数（非负）W={0,1,2,…} ⊂ 整数 I ⊂ 有理数 Q ⊂ 实数 R。一个数属于包含它最小家族的所有家族。
  2. Rational = can be written as ba​ with integers a,b, b=0. Its decimal either terminates (0.75) or repeats (0.36).有理数＝能写成 ba​（a,b 为整数，b=0）。它的小数要么有限（0.75），要么循环（0.36）。
  3. Irrational Q​ = real but NOT rational: decimals never end and never repeat, e.g. π, 2​, 35​. Rational and irrational together make up the reals; no number is both.无理数 Q​＝是实数但不是有理数：小数无限且不循环，如 π、2​、35​。有理数和无理数合起来就是实数，没有数同时属于两者。
  4. Simplify before you classify: 49​=7 and 3−8​=−2 are integers. An even root of a negative, like −4​, is not a real number at all.先化简再分类：49​=7、3−8​=−2 都是整数。负数的偶次方根（如 −4​）根本不是实数。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Write each number exactly as given. Note what it has: a root (which root, and of what), a fraction, a repeating bar, π.把每个数照原样写下来，看它带着什么：根号（几次方根、根号下是什么）、分数、循环节，还是 π。
  2. 🎯 Asked求什么
    Which sets does it belong to? List ALL of them from N, W, I, Q, Q​, R, or say "not real".它属于哪些数集？从 N、W、I、Q、Q​、R 中写出「全部」，或者写「不是实数」。
  3. ✏️ Picture it画出来
    Nested boxes: N inside W inside I inside Q, with Q​ beside Q, all inside R. Find the smallest box the number fits; it is also in every box around that one.一层套一层的盒子：N 在 W 里，W 在 I 里，I 在 Q 里；Q​ 和 Q 并排，都在 R 里。找出装得下这个数的最小盒子，外面套着它的每个盒子也都装着它。
  4. 🧰 Tool用什么工具
    Simplify first: work out roots of perfect squares and cubes, reduce fractions, turn repeating decimals into fractions. An even root of a negative is not real, so stop there.先化简：开得尽的平方根、立方根直接算出来，分数约分，循环小数化成分数。负数开偶次方不是实数，到此为止。
  5. ✅ Check检验
    Decimal test: it ends or repeats, so rational; it never ends and never repeats, so irrational. Then make sure you listed every bigger set too.小数检验：有限或循环，就是有理数；无限不循环，就是无理数。最后确认更大的数集也都写上了。

2Negative numbers: add, subtract, multiply负数的加减乘
Work out (−3)3.计算 (−3)3。

🩹 5-minute repair5 分钟补一补 · Negative numbers: add, subtract, multiply负数的加减乘 (Grade年级 7–9)
Subtracting a negative is adding: 5−(−3)=5+3=8. Same signs multiply to +, different signs to −. Squaring a negative is positive: (−4)2=16, but −42=−16 (the square happens first).减去负数等于加上它：5−(−3)=5+3=8。同号相乘得正，异号相乘得负。负数的平方是正的：(−4)2=16，但 −42=−16（先算平方）。
  1. −7−(−2): change "minus negative" to "plus": −7+2=−5.−7−(−2)：把「减负」改成「加」：−7+2=−5。
  2. (−3)(−5)=15 (same signs), (−3)(5)=−15 (different signs).(−3)(−5)=15（同号），(−3)(5)=−15（异号）。
  3. Plugging in x=−3 to x2: write brackets first, (−3)2=9.把 x=−3 代入 x2：先加括号，(−3)2=9。
