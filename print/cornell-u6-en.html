Solving by factoring & square roots因式分解法与直接开平方法

Formulas公式
AB=0 ⇒ A=0 or B=0 — Zero product property零积性质
(x−p)2=k ⇒ x=p±k​(k≥0) — Square root method直接开平方法
Remember记住
  • Zero product: get 0 on one side FIRST, then set each factor =0.零积法则：先让一边等于 0，再令每个因式 =0。
  • (…)2=k: take ±k​; k<0 → no real solution.(…)2=k：开方取 ±k​；k<0 → 无实数解。
Watch out当心
  • x(x−3)=10⇒x=10 or x−3=10 → expand: x2−3x−10=0, x=5,−2.x(x−3)=10⇒x=10 或 x−3=10 → 先展开：x2−3x−10=0，x=5,−2。
  • x2=49⇒x=7 → x=±7.x2=49⇒x=7 → 应为 x=±7。

Completing the square配方法

Formulas公式
x2+bx=k ⇒ (x+2b​)2=k+(2b​)2 — Completing the square in an equation方程中的配方
Remember记住
  • Make a=1 → move c → add (2b​)2 to BOTH sides → take ± ​.化 a=1 → 移常数 → 两边都加 (2b​)2 → 开方取 ±。
  • Equation: add to both sides. Vertex form of a function: add AND subtract on one side.解方程：两边同加。化函数顶点式：同一边加了再减。
Watch out当心
  • x2+6x=2: x2+6x+9=2 → add to both sides: =11.x2+6x=2：写成 x2+6x+9=2 → 两边都加：=11。
  • 2x2+8x=3: add 16 → divide by 2 first, then add 4 to both sides.2x2+8x=3：加 16 → 先除以 2，再两边加 4。

The quadratic formula求根公式

Formulas公式
x=2a−b±b2−4ac​​ — Quadratic formula (for ax2+bx+c=0, a=0)求根公式（适用于 ax2+bx+c=0，a=0）
Remember记住
  • x=2a−b±b2−4ac​​, only after the equation is ax2+bx+c=0.x=2a−b±b2−4ac​​，先化成 ax2+bx+c=0 再用。
  • Read a,b,c with their signs; b2 is never negative.a,b,c 连符号一起读；b2 永远不是负数。
Watch out当心
  • 24±23​​=4±3​ → 2±3​.24±23​​=4±3​ → 应为 2±3​。
  • x2=5x−2 read as c=−2 → move first: x2−5x+2=0, c=2.x2=5x−2 读成 c=−2 → 先移项：x2−5x+2=0，c=2。

The discriminant判别式

Formulas公式
D=b2−4ac — Discriminant of ax2+bx+c=0ax2+bx+c=0 的判别式
Remember记住
  • D=b2−4ac: D>0 two roots, D=0 one (double) root, D<0 no real roots.D=b2−4ac：D>0 两个根，D=0 一个（重）根，D<0 无实数根。
  • D a perfect square → rational roots → it factors.D 是完全平方数 → 有理根 → 能因式分解。
Watch out当心
  • D=0 means "no solution" → it means exactly one real root.D=0 当成「无解」→ 实际是恰有一个实数根。
  • x2+(k+1)x+4: b=k → b=k+1; square the whole bracket.x2+(k+1)x+4：b=k → 应为 b=k+1，整个括号一起平方。

Choosing a method & word problems选方法与应用题

Formulas公式
x=2a−b±b2−4ac​​ — Works for every quadratic对所有二次方程都适用
a2+b2=c2 — Pythagorean theorem (right-triangle problems)勾股定理（直角三角形问题）
Remember记住
  • Variable = what is asked; equation from area, Pythagoras or "height = value".设所求为未知数；由面积、勾股定理或「高度 = 某值」列方程。
  • A frame or path of width x adds 2x to each dimension.宽为 x 的边框或小路，使每个方向的长度都增加 2x。
Watch out当心
  • Border of width x: (10+x)(6+x) → (10+2x)(6+2x).宽为 x 的边框：(10+x)(6+x) → 应为 (10+2x)(6+2x)。
  • Ball at a height at t=1 and t=3: giving one → give both (up and down).小球在 t=1 和 t=3 都到某高度：只答一个 → 两个都要（上升和下降）。
