Angles in standard position标准位置角

Formulas公式
θcoterminal​=θ+360∘n, n∈Z — Coterminal angles同终边角
θR​=180∘−θ,  θ−180∘,  360∘−θ — Reference angle in quadrants II, III, IV第二、三、四象限的参考角
Remember记住
  • Start on the positive x-axis; counterclockwise is +, clockwise is −.从 x 轴正半轴出发；逆时针为正，顺时针为负。
  • Reference angle: acute angle to the x-axis. QII 180∘−θ, QIII θ−180∘, QIV 360∘−θ.参考角：终边与 x 轴所成锐角。第二象限 180∘−θ，第三 θ−180∘，第四 360∘−θ。
Watch out当心
  • Reference angle of 240∘ as 30∘ (to the y-axis) → 60∘ (to the x-axis).240∘ 的参考角写成 30∘（量到 y 轴）→ 应为 60∘（量到 x 轴）。
  • −45∘ coterminal with 45∘ → with 315∘.−45∘ 与 45∘ 终边相同 → 应与 315∘ 终边相同。

Special angles & the unit circle特殊角与单位圆

Formulas公式
sin30∘=21​, cos30∘=23​​, tan30∘=3​1​=33​​ — 30°
sin45∘=cos45∘=2​1​=22​​, tan45∘=1 — 45°
sin60∘=23​​, cos60∘=21​, tan60∘=3​ — 60°
Remember记住
  • 45-45-90: 1,1,2​. 30-60-90: 1,3​,2 (1 opposite 30∘).45-45-90：1,1,2​。30-60-90：1,3​,2（1 对 30∘）。
  • Value = reference-angle value with the CAST sign (All, Sin, Tan, Cos in QI to QIV).值 = 参考角的值，再配上 CAST 符号（第一到第四象限：全正、正弦、正切、余弦）。
Watch out当心
  • cos120∘=21​ → −21​ (cos negative in QII).cos120∘=21​ → 应为 −21​（第二象限余弦为负）。
  • sin60∘=21​ → 23​​ (side 1 is opposite 30∘).sin60∘=21​ → 应为 23​​（边 1 对 30∘）。

Trig ratios of any angle任意角的三角比

Formulas公式
r=x2+y2​ — Distance from the origin到原点的距离
sinθ=ry​,cosθ=rx​,tanθ=xy​ — Primary trig ratios of any angle任意角的三个基本三角比
Remember记住
  • r=x2+y2​>0; sinθ=ry​, cosθ=rx​, tanθ=xy​.r=x2+y2​>0；sinθ=ry​, cosθ=rx​, tanθ=xy​。
  • One ratio + quadrant: draw the triangle, find the third side, give x,y their quadrant signs.已知一个比值和象限：画三角形，求第三边，按象限给 x,y 定符号。
Watch out当心
  • P(−6,−8): r=−10 → r=10; only x,y carry signs.P(−6,−8)：r=−10 → 应为 r=10；只有 x,y 带符号。
  • tan−1(−34​)=−53.1∘ given as θ → in QII: 180∘−53.1∘=126.9∘.把 tan−1(−34​)=−53.1∘ 当作 θ → 在第二象限：180∘−53.1∘=126.9∘。

Formulas公式
QI: θR​QII: 180∘−θR​QIII: 180∘+θR​QIV: 360∘−θR​ — Angles from the reference angle由参考角写出各象限的角
Remember记住
  • Isolate the ratio first; ∣sinθ∣ or ∣cosθ∣>1 → no solution.先把三角比单独放一边；∣sinθ∣ 或 ∣cosθ∣>1 → 无解。
  • Reference angle from the POSITIVE value; the sign picks two quadrants (CAST).参考角用正值求；符号决定两个象限（CAST）。

  • sin−1(−0.6)=−36.9∘ used as the reference → reference is 36.9∘.把 sin−1(−0.6)=−36.9∘ 当参考角 → 参考角是 36.9∘。

The sine law正弦定理

Formulas公式
sinAa​=sinBb​=sinCc​ — Sine law (finding sides)正弦定理（求边）
asinA​=bsinB​=csinC​ — Sine law (finding angles)正弦定理（求角）
Remember记住
  • sinAa​=sinBb​=sinCc​; side a is opposite angle A.sinAa​=sinBb​=sinCc​；边 a 对角 A。
  • Needs a complete pair (side + opposite angle): AAS, ASA, SSA. SAS or SSS → cosine law.需要一组完整的「边＋对角」：AAS、ASA、SSA 可用。SAS、SSS → 用余弦定理。
Watch out当心
  • Rounding sinB to 2 decimals midway → keep the full calculator value to the end.中途把 sinB 四舍五入到两位 → 保留计算器全值到最后。
  • Calculator in radians (sin40≈0.745) → degrees: sin40∘≈0.643.计算器在弧度模式（sin40≈0.745）→ 改角度：sin40∘≈0.643。

The ambiguous case (SSA)两解情形（SSA）

Formulas公式
h=bsinA — Height to compare with a用来和 a 比较的高
B2​=180∘−B1​ — The second possible angle第二个可能的角
Remember记住
  • SSA (∠A, a, b): height h=bsinA.SSA（∠A、a、b）：高 h=bsinA。
  • Acute A: a<h none; a=h one; h<a<b TWO; a≥b one.A 为锐角：a<h 无；a=h 一个；h<a<b 两个；a≥b 一个。
Watch out当心
  • Stopping at B1​ → test 180∘−B1​ (valid if A+B2​<180∘).只算到 B1​ → 检验 180∘−B1​（若 A+B2​<180∘ 就成立）。
  • h=asinA → h=bsinA (the side next to A).h=asinA → 应为 h=bsinA（A 的邻边）。

The cosine law余弦定理

Formulas公式
c2=a2+b2−2abcosC — Cosine law (find a side)余弦定理（求边）
cosC=2aba2+b2−c2​ — Cosine law (find an angle)余弦定理（求角）
Remember记住
  • c2=a2+b2−2abcosC (c opposite C); C=90∘ gives Pythagoras.c2=a2+b2−2abcosC（c 对角 C）；C=90∘ 时就是勾股定理。
  • SAS → third side; SSS → angle from cosC=2aba2+b2−c2​.SAS → 求第三边；SSS → 由 cosC=2aba2+b2−c2​ 求角。
Watch out当心
  • 49+64−112cos50∘ as (49+64−112)cos50∘ → multiply first, then subtract.49+64−112cos50∘ 算成 (49+64−112)cos50∘ → 先乘后减。
  • Reporting c2=62.1 as c → c=62.1​≈7.9.把 c2=62.1 当成 c → c=62.1​≈7.9。
