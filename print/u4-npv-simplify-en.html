🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Copy the denominator on its own and factor it completely. Factor the numerator too.把分母单独抄出来，彻底分解。分子也分解。
  2. 🎯 Asked求什么 Two things: the non-permissible values, taken from the ORIGINAL denominator, and the simplest form with those NPVs written after it.两样东西：不允许值（从「原」分母找），以及最简式——后面要写上这些不允许值。
  3. ✏️ Picture it画出来 A number line with an open circle at each NPV: the holes the expression can never use, even after cancelling.在数轴上把每个不允许值画成空心圈：这些「洞」即使约分以后也永远不能用。
  4. 🧰 Tool用什么工具 Set each denominator factor =0 first. Then cancel only whole matching FACTORS; a pair like (3−x) and (x−3) cancels to −1.先令分母的每个因式 =0。然后只约完全相同的「因式」；像 (3−x) 和 (x−3) 这样的一对约成 −1。
  5. ✅ Check检验 Choose an easy allowed value such as x=0 or x=1. The original and your answer must give the same number.挑一个允许的简单值，比如 x=0 或 x=1。原式和你的答案算出来必须是同一个数。

⭐ Must know必须记住

  • NPVs: values that make the DENOMINATOR zero — factor it, set each factor =0.不允许值：使分母为零的值——把分母分解，每个因式 =0。
  • State NPVs from the ORIGINAL expression; a cancelled factor still counts.从原式写不允许值；约掉的因式照样算。
  • Cancel FACTORS, never terms; b−aa−b​=−1.只能约因式，不能约项；b−aa−b​=−1。

1. Cancelling terms instead of factors约掉的是项，不是因式
Simplify x2+3xx2+4x​ and state the NPVs.化简 x2+3xx2+4x​，并写出不允许值。
1 Cross out the x2 on top and bottom: 3x4x​.把上下的 x2 划掉：3x4x​。
2 Cancel x: 34​.约去 x：34​。

2. Taking the NPVs from the simplified form从化简后的式子找不允许值
Simplify x2+2x−15x2−25​ and state the NPVs.化简 x2+2x−15x2−25​，并写出不允许值。
1 Factor: (x+5)(x−3)(x−5)(x+5)​.分解：(x+5)(x−3)(x−5)(x+5)​。
2 Cancel: x−3x−5​.约分：x−3x−5​。
3 NPV: x=3.不允许值：x=3。

State the NPVs of x2−6xx2−4​.写出 x2−6xx2−4​ 的不允许值。
1 Set the top to zero: x2−4=(x−2)(x+2)=0.令分子为零：x2−4=(x−2)(x+2)=0。
2 NPVs: x=±2.不允许值：x=±2。

4. Treating opposite factors as equal把相反因式当成相同因式
Simplify x2−93−x​ and state the NPVs.化简 x2−93−x​，并写出不允许值。
1 Factor: (x−3)(x+3)3−x​, so x=±3.分解：(x−3)(x+3)3−x​，所以 x=±3。
2 3−x and x−3 are the same, so they cancel: x+31​.3−x 和 x−3 一样，约掉：x+31​。

5. Sign slip when taking out a negative提负号时符号出错
Simplify x2−8x+168−2x​ and state the NPV.化简 x2−8x+168−2x​，并写出不允许值。
1 Bottom: (x−4)2, so x=4.分母：(x−4)2，所以 x=4。
2 Top: 8−2x=−2(x+4).分子：8−2x=−2(x+4)。
3 Nothing cancels: (x−4)2−2(x+4)​.没有能约的：(x−4)2−2(x+4)​。

✍️ Which line goes wrong first, and why?哪一行最先出错？为什么？

Key (fold this part back)答案（可以折起来）
  1. line第 1 — The x2 is added to something, not multiplied, so it is a term, not a factor. Only factors that MULTIPLY the whole top and the whole bottom can cancel.x2 是和别的式子相加的，是「项」不是「因式」。只有乘在整个分子和整个分母上的因式才能约。 Factor first: x(x+3)x(x+4)​, NPVs x=0, −3; cancel x: x+3x+4​. (At x=1: 45​, not 34​.)先分解：x(x+3)x(x+4)​，不允许值 x=0, −3；约去 x：x+3x+4​。（x=1 时是 45​，不是 34​。）
  2. line第 3 — The NPV was read off the bottom AFTER (x+5) was cancelled, so x=−5 disappeared. At x=−5 the original is 00​, which is undefined.不允许值是在约掉 (x+5) 之后才看分母的，所以 x=−5 丢了。x=−5 时原式是 00​，没有意义。 Write the NPVs from the factored original bottom (x+5)(x−3): x=−5, 3.从分解后的原分母 (x+5)(x−3) 写不允许值：x=−5, 3。
  3. line第 1 — A zero on top is allowed; the value of the fraction is just 0. Only division by zero is a problem, so only the bottom matters.分子为零是允许的，分式的值就是 0。只有除以零才出问题，所以只看分母。 Bottom: x2−6x=x(x−6), so x=0 and x=6.分母：x2−6x=x(x−6)，所以 x=0，x=6。
  4. line第 2 — 3−x and x−3 are opposites, not equal: at x=5 they are −2 and 2. Opposites cancel to −1, not to 1.3−x 和 x−3 互为相反数，并不相等：x=5 时分别是 −2 和 2。相反因式约成 −1，不是 1。 3−x=−(x−3), so the result is −x+31​, x=±3. (At x=0: −93​=−31​ ✓.)3−x=−(x−3)，所以结果是 −x+31​，x=±3。（x=0 时：−93​=−31​ ✓。）
  5. line第 2 — Taking out −2 flips the sign of EVERY term inside: −2(x+4)=−2x−8, not 8−2x.提出 −2 时，括号里「每一项」都要变号：−2(x+4)=−2x−8，不是 8−2x。 8−2x=−2(x−4) (check: −2x+8 ✓). Cancel one (x−4): −x−42​, x=4.8−2x=−2(x−4)（检验：−2x+8 ✓）。约去一个 (x−4)：−x−42​，x=4。
