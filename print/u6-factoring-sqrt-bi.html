🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Is one side already 0? Is there a ready-made square like (x−3)2? Is there a common factor, such as an x in every term?有没有一边已经是 0？有没有现成的平方，比如 (x−3)2？每一项有没有公因式，比如都带 x？
  2. 🎯 Asked求什么 Every x that makes the equation true. A quadratic can have two, one or no real answers.让方程成立的所有 x。二次方程可能有两个、一个或没有实数解。
  3. ✏️ Picture it画出来 The answers are where y= left side meets y= right side. With 0 on one side, they are the x-intercepts of the parabola.答案就是 y=左边与 y=右边的交点。一边是 0 时，答案就是抛物线的 x 截距。
  4. 🧰 Tool用什么工具 Ready-made square: isolate it and take ± ​. Otherwise move everything to one side, factor, and set each factor to 0.有现成的平方：先把它单独留下，再开方取 ±。否则把所有项移到一边，分解，再令每个因式等于 0。
  5. ✅ Check检验 Put each answer back into the ORIGINAL equation. Two answers from ± should be equally far from the centre number.把每个答案代回「原」方程。± 得到的两个答案，到中间那个数的距离应该相等。

⭐ Must know必须记住

  • Zero product: get 0 on one side FIRST, then set each factor =0.零积法则：先让一边等于 0，再令每个因式 =0。
  • (…)2=k: take ±k​; k<0 → no real solution.(…)2=k：开方取 ±k​；k<0 → 无实数解。
  • Never divide by x: factor it out, or the root x=0 is lost.不要两边除以 x：把 x 提出来，否则丢掉根 x=0。
AB=0 ⇒ A=0 or B=0
(x−p)2=k ⇒ x=p±k​(k≥0)

1. Setting each factor equal to a number that is not zero让因式等于一个不是零的数

1 x−1=10 or x+2=10x−1=10 或 x+2=10

2. Dividing both sides by x两边同除以 x
Solve 4x2=28x.解 4x2=28x。
1 Divide both sides by 4x: x=7两边同除以 4x：x=7
2 So the only solution is x=7.所以唯一的解是 x=7。

Key (fold this part back)答案（可以折起来）
  1. line第 1 — The rule only works for 0: if a product is 0, one factor is 0. Two numbers can multiply to 10 in endless ways (2×5, 4×2.5, …).这条规则只对 0 成立：乘积为 0，才有一个因式是 0。两个数相乘等于 10 的方式有无数种（2×5、4×2.5……）。 Expand and move 10: x2+x−12=0, (x+4)(x−3)=0, so x=−4 or x=3.展开并移项：x2+x−12=0，(x+4)(x−3)=0，得 x=−4 或 x=3。
  2. line第 1 — Dividing by x quietly assumes x=0, and x=0 is one of the answers: 4(0)2=28(0).除以 x 时默认了 x=0，可 x=0 正是一个解：4(0)2=28(0)。 4x2−28x=0, 4x(x−7)=0, so x=0 or x=7.4x2−28x=0，4x(x−7)=0，得 x=0 或 x=7。
  3. line第 1 — The  ​ key on a calculator gives only the positive root, but (−4)2 is 16 too.计算器的  ​ 键只给正根，可 (−4)2 也等于 16。 x+3=±4, so x=1 or x=−7.x+3=±4，得 x=1 或 x=−7。
  4. line第 1 — The 2 MULTIPLIES the square, so it is undone by dividing by 2, not by subtracting 2.2 是「乘」在平方上的，要用除以 2 来还原，不是减 2。 (x+1)2=16, x+1=±4, so x=3 or x=−5.(x+1)2=16，x+1=±4，得 x=3 或 x=−5。
