🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Label the known angle A, the side across from it a, and the other known side b (it touches A). Is A acute or obtuse?标出已知角 A、它的对边 a、另一条已知边 b（它挨着 A）。A 是锐角还是钝角？
  2. 🎯 Asked求什么 How many triangles (0, 1 or 2)? If asked to solve, every missing angle and side for EACH triangle, rounded as stated.有几个三角形（0、1 或 2）？如果要求解，每个三角形的所有未知角和边都要求出，按要求取近似。
  3. ✏️ Picture it画出来 Draw A with side b to C, drop the height h from C, then swing side a from C like a gate and count where it hits the base.画出角 A 和边 b 到 C，从 C 作高 h，再把边 a 从 C 像门一样摆下来，数它碰到底边几次。
  4. 🧰 Tool用什么工具 h=bsinA. Acute A: a<h none, a=h one (right), h<a<b two, a≥b one. Then sinB=absinA​ and B2​=180∘−B1​.h=bsinA。A 为锐角时：a<h 无解，a=h 一解（直角），h<a<b 两解，a≥b 一解。再用 sinB=absinA​，B2​=180∘−B1​。
  5. ✅ Check检验 For each triangle: angles add to 180∘, and the longest side faces the largest angle. B2​ only counts if A+B2​<180∘.每个三角形：三角之和 180∘，最长边对最大角。只有 A+B2​<180∘ 时 B2​ 才算数。

  • Two triangles: B2​=180∘−B1​; finish each triangle separately.两个三角形：B2​=180∘−B1​；两个三角形分别解完。
