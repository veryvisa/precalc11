🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Which angle, which ratio? Note where the angle sits: between which two axes (0∘, 90∘, 180∘, 270∘, 360∘)?哪个角、哪个比？看角落在哪两条坐标轴之间（0∘、90∘、180∘、270∘、360∘）。
  2. 🎯 Asked求什么 An EXACT value: fractions and roots, no decimals. For a point on the unit circle, both coordinates.要「精确值」：分数和根号，不要小数。若问单位圆上的点，要两个坐标。
  3. ✏️ Picture it画出来 Sketch the terminal arm, drop a line to the x-axis, and draw the special triangle it matches: 45-45-90 with 1,1,2​, or 30-60-90 with 1,3​,2.画出终边，向 x 轴作垂线，再画出对应的特殊三角形：45-45-90 边长 1,1,2​，或 30-60-90 边长 1,3​,2。
  4. 🧰 Tool用什么工具 Reference angle (the gap to the x-axis) → value from the triangle with SOH CAH TOA → sign from CAST. On an axis, read the unit-circle point instead.参考角（到 x 轴的夹角）→ 用 SOH CAH TOA 从三角形读数 → 用 CAST 定符号。若终边在坐标轴上，直接读单位圆上的点。
  5. ✅ Check检验 Size: sine and cosine are between −1 and 1; 23​​≈0.87 is the big one, 21​ the small one. Does the sign match CAST? A calculator decimal can confirm.看大小：sin、cos 都在 −1 与 1 之间；23​​≈0.87 是大的，21​ 是小的。符号和 CAST 对得上吗？可以用计算器的小数核对。
