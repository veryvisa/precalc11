🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 The interval (usually 0∘≤θ<360∘) and the equation. Isolate the ratio: sinθ, cosθ or tanθ equals a number. If sine or cosine is outside [−1,1], stop: no solution.看区间（通常是 0∘≤θ<360∘）和方程。先把三角比分离出来：sinθ、cosθ 或 tanθ 等于一个数。若 sin 或 cos 不在 [−1,1] 内，停：无解。
  2. 🎯 Asked求什么 ALL the angles in the interval, exact if the value is special, otherwise rounded as asked. Usually two; 0 and ±1 give angles on the axes.区间内的「所有」角：特殊值写精确角，否则按要求取近似。通常有两个；0 和 ±1 对应坐标轴上的角。
  3. ✏️ Picture it画出来 A quick unit circle: mark where the ratio is positive or negative (CAST), then draw two terminal arms with the same reference angle.画一个简单的单位圆：用 CAST 标出该比值为正或为负的象限，再画两条参考角相同的终边。
  4. 🧰 Tool用什么工具 Reference angle from the POSITIVE value (special triangle or inverse key). Then Q I: θR​, Q II: 180∘−θR​, Q III: 180∘+θR​, Q IV: 360∘−θR​.用「正值」求参考角（特殊三角形或反三角键）。然后第一象限 θR​，第二象限 180∘−θR​，第三象限 180∘+θR​，第四象限 360∘−θR​。
  5. ✅ Check检验 Put each angle into the ORIGINAL equation (calculator in degrees). Count them: did you find both?把每个角代回「原」方程（计算器用角度制）。数一数：两个都找到了吗？

⭐ Must know必须记住

  • Isolate the ratio first; ∣sinθ∣ or ∣cosθ∣>1 → no solution.先把三角比单独放一边；∣sinθ∣ 或 ∣cosθ∣>1 → 无解。
  • Reference angle from the POSITIVE value; the sign picks two quadrants (CAST).参考角用正值求；符号决定两个象限（CAST）。
  • 0 and ±1 are quadrantal: read them off the unit circle.0 和 ±1 对应轴上角：直接从单位圆读。
