Thinking map — keep it next to you while you work思路图——做题时放在手边

🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Circle every base and its exponent. Mark each bracket and the power outside it, and every negative or zero exponent.圈出每个底数和它的指数。标出每个括号以及括号外的指数，还有所有负指数、零指数。
  2. 🎯 Asked求什么 One tidy expression: each base written once, the numbers multiplied out, and positive exponents only (or just a number).一个整洁的式子：每个底数只出现一次，数字算出来，只用正指数（或者就是一个数）。
  3. ✏️ Picture it画出来 Draw an arrow from the outside power to EVERY factor in the bracket, the number included. If a rule feels shaky, write it out once: x3⋅x2=xxx⋅xx.从括号外的指数画箭头指向括号里的「每一个」因数，数字也算。哪条法则没把握，就展开写一次：x3⋅x2=xxx⋅xx。
  4. 🧰 Tool用什么工具 Brackets first (multiply exponents, power the number), then the numbers, then one base at a time: add for ×, subtract for ÷. Last, move negative exponents across the fraction bar.先去括号（指数相乘，数字也乘方），再算数字，然后一个底数一个底数地处理：相乘指数相加，相除指数相减。最后把负指数移到分数线另一边。
  5. ✅ Check检验 Put a small number such as x=2, y=1 into the original and into your answer; both must give the same value. Then look: no negative exponent left.把 x=2、y=1 这样的小数代入原式和你的答案，两者的值必须相同。再看一眼：不能留负指数。

⭐ Must know必须记住

  • Same base: multiply → add exponents, divide → subtract, power of a power → multiply.同底数：相乘指数相加，相除指数相减，乘方的乘方指数相乘。
  • An outside power hits every factor, numbers too: (3x2)3=27x6.括号外的指数作用到每个因式上，系数也要乘方：(3x2)3=27x6。
  • a0=1; a−n=an1​ — a negative exponent means reciprocal, never a negative number.a0=1；a−n=an1​——负指数表示倒数，不是负数。
am⋅an=am+n,anam​=am−n,(am)n=amn
(ab)n=anbn,(ba​)n=bnan​

Key (fold this part back)答案（可以折起来）
  1. line第 1 — The eye goes to the letter, so the power is only given to x3. But the outside 2 squares the WHOLE bracket, and 5 is part of it.眼睛只盯着字母，于是指数只给了 x3。可是外面的 2 是把「整个」括号平方，5 也在括号里。 (5x3)2=52⋅x6=25x6.(5x3)2=52⋅x6=25x6。
  2. line第 1 — A minus sign usually means "negative", so it feels natural here too. But a negative EXPONENT means "one over": 3−2=321​.减号平时表示「负数」，所以这里也顺手当成负数。可是负「指数」的意思是「取倒数」：3−2=321​。 3−2=91​, so 91​+1=910​.3−2=91​，所以 91​+1=910​。
  3. line第 1 — The two rules got swapped. "Add" is for xa⋅xb; a power OF a power means the factor is repeated 3 times, so the exponents multiply: (−2)(3).两条法则弄混了。「相加」用于 xa⋅xb；幂的乘方是把因数重复 3 次，所以指数相乘：(−2)(3)。 (x−2)3=x−6, then x−6⋅x4=x−2=x21​.(x−2)3=x−6，再 x−6⋅x4=x−2=x21​。
  4. line第 2 — The rule is "top exponent minus bottom exponent", and the bottom one is −3. Dropping the brackets turns 4−(−3) into 4−3.法则是「上面的指数减下面的指数」，而下面的是 −3。不写括号，4−(−3) 就变成了 4−3。 a4−(−3)=a7, so the answer is 3a7. (Or move a−3 up as a3: a4⋅a3=a7.)a4−(−3)=a7，答案是 3a7。（也可以把 a−3 移到上面变成 a3：a4⋅a3=a7。）
  5. line第 1 — "Anything to the power 0 is 1" was applied to the whole term. In 4x0 the 0 belongs only to x; there is no bracket, so the 4 stays.把「任何数的 0 次方都是 1」用到了整个项上。4x0 里的 0 只属于 x；没有括号，4 不变。 4x0=4⋅1=4 and (4x)0=1, so 4+1=5.4x0=4⋅1=4，(4x)0=1，所以 4+1=5。
