🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Put the equation in the form ax2+bx+c=0 (everything on one side), then write a, b, c with their signs. If there is a k, note which letter it lives in.先化成 ax2+bx+c=0（全部移到一边），再写出带符号的 a、b、c。若有 k，看清它在哪个字母里。
  2. 🎯 Asked求什么 "How many roots" or "which k"? Equal roots → D=0; two different → D>0; none → D<0; "real roots" (at least one) → D≥0.问的是「几个根」还是「k 取什么」？两等根 → D=0；两不等根 → D>0；无实根 → D<0；「有实数根」（至少一个）→ D≥0。
  3. ✏️ Picture it画出来 The parabola and the x-axis: it crosses twice (D>0), just touches at the vertex (D=0), or misses (D<0).抛物线和 x 轴：交两次（D>0）、顶点刚好碰到（D=0）、碰不到（D<0）。
  4. 🧰 Tool用什么工具 D=b2−4ac, with brackets around a negative b. With k, write D in terms of k, then solve the equation or inequality.D=b2−4ac，负的 b 要加括号。含 k 时，先用 k 写出 D，再解方程或不等式。
  5. ✅ Check检验 Put your k back: D=0 should give a perfect square. For an inequality, test one k on each side. If k multiplies x2, make sure k=0.把 k 代回去：D=0 时应得到完全平方式。不等式就在分界点两边各试一个 k。若 k 是 x2 的系数，要保证 k=0。

⭐ Must know必须记住

  • D=b2−4ac: D>0 two roots, D=0 one (double) root, D<0 no real roots.D=b2−4ac：D>0 两个根，D=0 一个（重）根，D<0 无实数根。
  • D a perfect square → rational roots → it factors.D 是完全平方数 → 有理根 → 能因式分解。
  • Unknown k: write D in k, set =0, >0 or <0, solve.含 k：用 k 写出 D，令 =0、>0 或 <0，解出 k。
D=b2−4ac

Key (fold this part back)答案（可以折起来）
  1. line第 2 — "Zero" sounds like "nothing". But 0​=0, so ±D​ gives the same number twice: one repeated root.「零」听起来像「没有」。但 0​=0，所以 ±D​ 两次得到同一个数：一个重根。 D=0: two equal real roots. In fact (x−5)2=0, so x=5.D=0：两个相等的实数根。也就是 (x−5)2=0，x=5。
  2. line第 1 — Without brackets, −62 means −(62)=−36. The whole b=−6 must be squared: (−6)2=36. A square is never negative.不加括号时 −62 表示 −(62)=−36。要把整个 b=−6 平方：(−6)2=36。平方永远不会是负数。 D=36−24=12>0: two different real roots (irrational, since 12 is not a perfect square).D=36−24=12>0：两个不相等的实数根（是无理数，因为 12 不是完全平方数）。
  3. line第 1 — b is everything in front of x, so b=k+1. Squaring only k gives a different equation.b 是 x 前面的全部，所以 b=k+1。只平方 k 就成了另一个方程。 D=(k+1)2−36=0⇒k+1=±6⇒k=5 or k=−7.D=(k+1)2−36=0⇒k+1=±6⇒k=5 或 k=−7。
  4. line第 3 — k=0 is less than 4, but then the equation is 4x+1=0, which is linear and has only one root.k=0 也小于 4，但这时方程是 4x+1=0，是一次方程，只有一个根。 Keep D>0 and add k=0: k<4 and k=0.保留 D>0，再加上 k=0：k<4 且 k=0。
  5. line第 3 — Dividing both sides by −4 reverses the inequality. A quick test shows it: k=0 gives D=36>0, two roots, so k<9 cannot be right.两边除以 −4，不等号要反向。试一下就知道：k=0 时 D=36>0，有两个根，所以 k<9 不可能对。 −4k<−36⇒k>9. Test k=10: D=36−40=−4<0 ✓.−4k<−36⇒k>9。试 k=10：D=36−40=−4<0 ✓。
