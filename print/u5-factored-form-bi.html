🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Write the zeros (x-intercepts) and the one extra point. A graph that only touches the x-axis gives a double zero.写下零点（x 截距）和多给的那个点。图象只碰到 x 轴的，是一个重零点。
  2. 🎯 Asked求什么 Which form is wanted: factored, vertex or standard? Or is it the vertex or the max/min value?题目要哪种形式：交点式、顶点式还是一般式？还是要顶点或最值？
  3. ✏️ Picture it画出来 Mark the zeros on the x-axis and the axis halfway between them. If the extra point is above the x-axis between the zeros, the parabola opens down, so expect a<0.在 x 轴上标出零点，再在中间画对称轴。如果多给的点在两个零点之间且在 x 轴上方，抛物线开口向下，a 应为负。
  4. 🧰 Tool用什么工具 Write y=a(x−r)(x−s) with the bracket signs opposite to the zeros, put in the extra point and solve for a.写出 y=a(x−r)(x−s)，括号里的符号与零点相反；代入多给的点，解出 a。
  5. ✅ Check检验 The extra point must fit, and the sign of a must match your sketch. Expand only at the end if standard form is asked.多给的点必须满足方程，a 的符号要和草图一致。题目要一般式时，最后再展开。

Key (fold this part back)答案（可以折起来）
  1. line第 1 — The numbers were copied straight out of the brackets. A zero is where a bracket equals 0: x+2=0 gives x=−2.直接把括号里的数抄了出来。零点是让括号等于 0 的值：x+2=0 得 x=−2。 Zeros −2 and 8; axis x=2−2+8​=3.零点 −2 和 8；对称轴 x=2−2+8​=3。
  2. line第 1 — Many parabolas share the same two zeros; they differ only by a. The point (1,−8) was never used, and at x=1 this gives −4, not −8.有无数条抛物线有相同的两个零点，它们只差一个 a。点 (1,−8) 根本没用上，而且这个式子在 x=1 时是 −4，不是 −8。 y=a(x+1)(x−3); −8=a(2)(−2)=−4a, so a=2.y=a(x+1)(x−3)；−8=a(2)(−2)=−4a，得 a=2。
  3. line第 2 — The brackets were worked out, and the −3 in front was forgotten. It multiplies everything.只算了两个括号，忘了前面的 −3。它要乘整个式子。 y=−3(3)(−3)=27. Opens down, so (4,27) is a maximum.y=−3(3)(−3)=27。开口向下，(4,27) 是最高点。
  4. line第 2 — (4)(−2) is −8, not 8. A quick picture warns you too: a point above the x-axis between the zeros means the parabola opens down.(4)(−2) 是 −8，不是 8。画个草图也能提醒你：两个零点之间、x 轴上方的点说明开口向下。 16=−8a, so a=−2.16=−8a，所以 a=−2。
  5. line第 2 — The 3 was used to make the trinomial easier, then left behind. Without it the curve is only a third as steep, and every y-value is wrong.提出 3 是为了让三项式好分解，结果把它落下了。没有它，曲线只有原来三分之一陡，每个 y 值都不对。 Keep the 3 in front: y=3(x−4)(x+2).把 3 留在前面：y=3(x−4)(x+2)。
