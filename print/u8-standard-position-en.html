🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Read the angle and its sign: positive turns counterclockwise, negative turns clockwise. Is it bigger than 360∘ or below 0∘?读出这个角和它的符号：正角逆时针转，负角顺时针转。它大于 360∘ 吗？小于 0∘ 吗？
  2. 🎯 Asked求什么 What is wanted: the quadrant, the reference angle (acute, measured to the x-axis), or coterminal angles? All answers in degrees.要求的是什么：所在象限、参考角（锐角，量到 x 轴），还是同终边角？答案都用度。
  3. ✏️ Picture it画出来 A 3-second sketch: axes marked 90∘, 180∘, 270∘, 360∘, the terminal arm, and a small arc from the arm to the x-axis.花 3 秒画草图：坐标轴上标出 90∘、180∘、270∘、360∘，画出终边，再画一小段从终边到 x 轴的弧。
  4. 🧰 Tool用什么工具 First add or subtract 360∘ until the angle is between 0∘ and 360∘. Then find the quadrant, then use that quadrant's rule: θ, 180∘−θ, θ−180∘ or 360∘−θ.先加或减 360∘，直到角落在 0∘ 到 360∘ 之间；再定象限；最后用该象限的公式：θ、180∘−θ、θ−180∘ 或 360∘−θ。
  5. ✅ Check检验 The reference angle must be between 0∘ and 90∘ and match the sketch. Two angles are coterminal only if their difference is a multiple of 360∘.参考角必须在 0∘ 到 90∘ 之间，并且和草图对得上。两个角只有在差是 360∘ 的整数倍时才同终边。

⭐ Must know必须记住

  • Start on the positive x-axis; counterclockwise is +, clockwise is −.从 x 轴正半轴出发；逆时针为正，顺时针为负。
  • Reference angle: acute angle to the x-axis. QII 180∘−θ, QIII θ−180∘, QIV 360∘−θ.参考角：终边与 x 轴所成锐角。第二象限 180∘−θ，第三 θ−180∘，第四 360∘−θ。
  • Coterminal: θ±360∘n.终边相同的角：θ±360∘n。
θcoterminal​=θ+360∘n, n∈Z
θR​=180∘−θ,  θ−180∘,  360∘−θ

🔍 Common-errors sheet常见错误单

1. Measuring the reference angle to the y-axis把参考角量到了 y 轴
Find the reference angle of 240∘.求 240∘ 的参考角。
1 240∘ is in quadrant III.240∘ 在第三象限。
2 From the arm to the nearest axis, 270∘: 270∘−240∘=30∘.从终边量到最近的轴 270∘：270∘−240∘=30∘。

2. Using another quadrant's rule用错了象限的公式
Find the reference angle of 320∘.求 320∘ 的参考角。
1 320∘ is in quadrant IV.320∘ 在第四象限。
2 Reference angle =320∘−180∘=140∘.参考角 =320∘−180∘=140∘。

✍️ Which line goes wrong first, and why?哪一行最先出错？为什么？

3. Thinking a negative angle shares the arm of the positive one以为负角和对应的正角终边相同
Give the angle between 0∘ and 360∘ that is coterminal with −70∘.写出 0∘ 到 360∘ 之间与 −70∘ 终边相同的角。
1 Coterminal means the same size, so drop the minus sign: 70∘.同终边就是大小一样，所以去掉负号：70∘。
2 Answer: 70∘.答案：70∘。

4. Turning a negative angle the wrong way负角转错了方向
State the quadrant and reference angle of −120∘.写出 −120∘ 所在象限和参考角。
1 120∘ is between 90∘ and 180∘, so −120∘ is in quadrant II.120∘ 在 90∘ 和 180∘ 之间，所以 −120∘ 在第二象限。
2 Reference angle 180∘−120∘=60∘.参考角 180∘−120∘=60∘。

5. Taking off only one full turn只减了一整圈
For 820∘, find the quadrant and the reference angle.对 820∘，求所在象限和参考角。
1 820∘−360∘=460∘.820∘−360∘=460∘。
2 460∘ is past 180∘, so quadrant III, and the reference angle is 460∘−180∘=280∘.460∘ 超过了 180∘，所以在第三象限，参考角是 460∘−180∘=280∘。

✍️ Which line goes wrong first, and why?哪一行最先出错？为什么？

Key (fold this part back)答案（可以折起来）
  1. line第 2 — The arm looks closer to the y-axis, so it feels natural to measure there. But a reference angle is always measured to the x-axis.终边看起来离 y 轴更近，所以很自然就量到那里去了。但参考角永远量到 x 轴。 Measure back to the negative x-axis at 180∘: 240∘−180∘=60∘.量回到 x 轴负半轴（180∘）：240∘−180∘=60∘。
  2. line第 2 — The rules were learned as a list, and the wrong line of the list was picked without a sketch. 140∘ is not even acute, which is a warning sign.公式是当成一张表背下来的，没画草图就挑错了一行。140∘ 连锐角都不是，这本身就是警报。 Quadrant IV is 360∘−θ: 360∘−320∘=40∘.第四象限用 360∘−θ：360∘−320∘=40∘。
  3. line第 1 — The minus sign is a direction, not decoration. −70∘ turns clockwise into quadrant IV; 70∘ turns the other way into quadrant I.负号表示方向，不是装饰。−70∘ 顺时针转到第四象限；70∘ 逆时针转到第一象限。 Add a full turn: −70∘+360∘=290∘.加一整圈：−70∘+360∘=290∘。
  4. line第 1 — The quadrant was read as if the angle turned counterclockwise. Clockwise, −90∘ is straight down and −180∘ is the negative x-axis, so −120∘ lands in quadrant III.把它当成逆时针转来读象限了。顺时针转时，−90∘ 指向正下方，−180∘ 是 x 轴负半轴，所以 −120∘ 落在第三象限。 −120∘+360∘=240∘: quadrant III, reference angle 240∘−180∘=60∘. (The 60∘ happened to be right; the quadrant was not.)−120∘+360∘=240∘：第三象限，参考角 240∘−180∘=60∘。（60∘ 碰巧对了，象限却错了。）
  5. line第 2 — The first subtraction was fine, but 460∘ is still more than a full turn. The quadrant rules only work between 0∘ and 360∘; a 280∘ "reference angle" is the giveaway.第一步减法没错，但 460∘ 仍然超过一整圈。象限公式只在 0∘ 到 360∘ 之间才能用；算出 280∘ 的「参考角」就露馅了。 Take off another turn: 460∘−360∘=100∘, quadrant II, reference angle 180∘−100∘=80∘.再减一圈：460∘−360∘=100∘，第二象限，参考角 180∘−100∘=80∘。
