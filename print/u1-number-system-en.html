🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Write each number exactly as given. Note what it has: a root (which root, and of what), a fraction, a repeating bar, π.把每个数照原样写下来，看它带着什么：根号（几次方根、根号下是什么）、分数、循环节，还是 π。
  2. 🎯 Asked求什么 Which sets does it belong to? List ALL of them from N, W, I, Q, Q​, R, or say "not real".它属于哪些数集？从 N、W、I、Q、Q​、R 中写出「全部」，或者写「不是实数」。
  3. ✏️ Picture it画出来 Nested boxes: N inside W inside I inside Q, with Q​ beside Q, all inside R. Find the smallest box the number fits; it is also in every box around that one.一层套一层的盒子：N 在 W 里，W 在 I 里，I 在 Q 里；Q​ 和 Q 并排，都在 R 里。找出装得下这个数的最小盒子，外面套着它的每个盒子也都装着它。
  4. 🧰 Tool用什么工具 Simplify first: work out roots of perfect squares and cubes, reduce fractions, turn repeating decimals into fractions. An even root of a negative is not real, so stop there.先化简：开得尽的平方根、立方根直接算出来，分数约分，循环小数化成分数。负数开偶次方不是实数，到此为止。
  5. ✅ Check检验 Decimal test: it ends or repeats, so rational; it never ends and never repeats, so irrational. Then make sure you listed every bigger set too.小数检验：有限或循环，就是有理数；无限不循环，就是无理数。最后确认更大的数集也都写上了。

⭐ Must know必须记住

  • N⊂W⊂I⊂Q⊂R; 0 is whole but not natural.N⊂W⊂I⊂Q⊂R；0 是非负整数（W），但不是自然数。
  • Rational = ba​ with integers a,b: decimal ends or repeats. Irrational: never ends, never repeats.有理数＝两个整数之比 ba​，小数会终止或循环；无理数的小数不终止也不循环。
  • Simplify before classifying: 49​=7, 3−8​=−2; −4​ is not real.先化简再分类：49​=7，3−8​=−2；−4​ 不是实数。

Key (fold this part back)答案（可以折起来）
  1. line第 2 — Finding the first set that fits feels like the end of the job. But the sets are nested, so 9 also sits in every bigger set.找到第一个装得下它的数集，就以为做完了。可是数集一层套一层，9 也在每个更大的数集里。 Climb the ladder: 9∈N,W,I,Q,R.沿梯子往上写：9∈N,W,I,Q,R。
  2. line第 1 — Only whole numbers were tried as perfect squares. Decimals can be perfect squares too: 0.32=0.09.只拿整数去想完全平方数。小数也可以是完全平方：0.32=0.09。 0.09​=0.3=103​, a ratio of integers, so it is rational.0.09​=0.3=103​，是两个整数之比，所以是有理数。
  3. line第 2 — Rational means a ratio of two INTEGERS. The shape matches, but the top, 3​, is not an integer.有理数的意思是两个「整数」之比。形状对上了，但分子 3​ 不是整数。 3​ is irrational, and half of an irrational number is still irrational.3​ 是无理数，无理数的一半仍是无理数。
  4. line第 1 — It copies the cube-root habit (3−8​=−2). But (−4)2=16, not −16: no real number squares to a negative.照搬了立方根的习惯（3−8​=−2）。可是 (−4)2=16，不是 −16：没有实数的平方是负数。 Stop at line 1: −16​ is not a real number, so it is in none of the sets.在第 1 行就停：−16​ 不是实数，不属于任何一个数集。
  5. line第 2 — The screen only has room for about ten digits. The block 538461 has six digits, so its repeat is cut off by rounding.屏幕只放得下十位左右。循环节 538461 有六位，它的第二轮被四舍五入截掉了。 Decide from the exact form: 137​ is a ratio of integers, so it is rational (0.538461).按精确形式判断：137​ 是两个整数之比，所以是有理数（0.538461）。
