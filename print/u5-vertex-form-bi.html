🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 Read a, p and q. Rewrite the bracket as (x−p) so the sign of p is honest: (x+3) means p=−3.读出 a、p、q。把括号写成 (x−p) 的样子，p 的符号就不会看错：(x+3) 表示 p=−3。
  2. 🎯 Asked求什么 Which one is wanted: the vertex, axis, max or min, range, the transformations, the number of x-intercepts, or the equation itself (find a)?要的是哪一样：顶点、对称轴、最值、值域、变换过程、x 截距个数，还是方程本身（求 a）？
  3. ✏️ Picture it画出来 Plot the vertex, draw the axis x=p as a dashed line, then step out 1, 2, 3 units and go up a, 4a, 9a on both sides.先描顶点，用虚线画对称轴 x=p，再从顶点横走 1、2、3，竖走 a、4a、9a，两边都画。
  4. 🧰 Tool用什么工具 To describe: a stretches or flips, p moves left or right, q moves up or down. To find the equation: write y=a(x−p)2+q with the vertex filled in, substitute the OTHER point, solve for a.描述图象：a 管伸缩和翻折，p 管左右，q 管上下。求方程：把顶点填进 y=a(x−p)2+q，代入「另一个」点，解出 a。
  5. ✅ Check检验 Put x=p into your equation: you must get q. Put the other point in: it must work. Sense check: a point below the vertex means a<0.把 x=p 代入方程，必须得到 q。把另一个点代入，也必须成立。合理性：点在顶点下方，a 就小于 0。

⭐ Must know必须记住

  • y=a(x−p)2+q: vertex (p,q), axis x=p. (x+3)2 means p=−3.y=a(x−p)2+q：顶点 (p,q)，对称轴 x=p。(x+3)2 表示 p=−3。
  • ∣a∣>1 narrower, ∣a∣<1 wider, a<0 flips. From the vertex: over 1, 2, 3 → up a, 4a, 9a.∣a∣>1 变窄，∣a∣<1 变宽，a<0 翻转。从顶点出发：右移 1、2、3 → 上升 a、4a、9a。
  • x-intercepts: a,q opposite signs → 2; q=0 → 1; same signs → 0.x 截距个数：a,q 异号 → 2 个；q=0 → 1 个；同号 → 0 个。

Key (fold this part back)答案（可以折起来）
  1. line第 1 — The form is (x−p), so (x+2)=(x−(−2)) means p=−2. The bracket is zero at x=−2, and that is where the vertex sits.顶点式写的是 (x−p)，(x+2)=(x−(−2))，所以 p=−2。括号在 x=−2 时等于零，顶点就在那里。 p=−2, q=−7: vertex (−2,−7).p=−2，q=−7：顶点 (−2,−7)。
  2. line第 3 — Both 22 and (−2)2 equal 4. A parabola is symmetric, so an intercept at 5 (2 right of the axis x=3) has a partner 2 to the left.22 和 (−2)2 都等于 4。抛物线是对称的，5 在对称轴 x=3 右边 2 处，左边 2 处一定还有一个截距。 x−3=±2, so x=5 or x=1.x−3=±2，所以 x=5 或 x=1。
  3. line第 2 — The vertex is already built into the equation, so it always fits and tells you nothing about a. Only the other point pins a down.顶点已经写进方程了，代进去永远成立，对求 a 毫无帮助。只有另一个点才能定出 a。 Use (5,10): 10=a(2)2+2=4a+2, so a=2 and y=2(x−3)2+2.用 (5,10)：10=a(2)2+2=4a+2，所以 a=2，y=2(x−3)2+2。
  4. line第 1 — The factor is a itself, not its flip. Every height is multiplied by 31​: from the vertex, over 3 goes up only 9⋅31​=3 instead of 9, so the graph is flatter and wider.伸缩因子就是 a 本身，不是它的倒数。每个高度都乘以 31​：从顶点横走 3，只上升 9⋅31​=3 而不是 9，所以图象更平、更宽。 Vertical stretch by a factor of 31​ (wider), then 1 right and 4 up. Vertex (1,4).竖直方向伸缩为原来的 31​（变宽），再向右 1、向上 4。顶点 (1,4)。
  5. line第 2 — That is only true if the parabola opens UP. Here a=−3<0, so it opens down from a vertex that is already below the axis and never reaches it.只有开口向上时才这样。这里 a=−3<0，开口向下，顶点本来就在 x 轴下方，图象永远够不到 x 轴。 a and q are both negative (same signs), so there are 0 x-intercepts.
