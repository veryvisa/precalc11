🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 What is under the root, and what is on the other side? Write the restriction: inside ≥0, and if the other side has x, it must be ≥0 too.根号里是什么？另一边是什么？写出限制条件：根号内 ≥0；另一边含 x 时它也必须 ≥0。
  2. 🎯 Asked求什么 Every x that makes the ORIGINAL equation true. There may be two, one or none.让原方程成立的所有 x——可能有两个、一个，或者没有。
  3. ✏️ Picture it画出来 Two graphs, y= left side and y= right side; answers are where they meet. A root curve can never meet a negative number.两个图象：y=左边、y=右边，答案就是交点。根式曲线永远碰不到负数。
  4. 🧰 Tool用什么工具 Isolate the radical, square BOTH WHOLE sides, then solve the linear or quadratic equation you get.先孤立根式，再把两边「整体」平方，然后解得到的一次或二次方程。
  5. ✅ Check检验 Put every answer back into the ORIGINAL equation. Mark ✓ or ✗; reject the ✗ ones (extraneous).把每个答案代回原方程，标 ✓ 或 ✗；✗ 的是增根，舍去。

⭐ Must know必须记住

  • Restrictions → ISOLATE the radical → raise to the index → solve → CHECK in the original.写限制条件 → 孤立根式 → 两边乘方 → 解方程 → 代回原方程检验。
  • Squaring can create extraneous roots: reject any root that fails the original.平方可能产生增根：不满足原方程的根要舍去。
  • …​≥0: so x​=−4 has no solution, and …​=x−3 needs x≥3.…​≥0：所以 x​=−4 无解，…​=x−3 要求 x≥3。

Key (fold this part back)答案（可以折起来）
  1. line第 1 — You cannot square term by term. (x+5​+1)2 has a middle term 2x+5​.不能逐项平方。(x+5​+1)2 有中间项 2x+5​。 Isolate first: x+5​=x−1, then x+5=x2−2x+1, x2−3x−4=0, x=4 or −1; only x=4 checks.先孤立：x+5​=x−1，再 x+5=x2−2x+1，x2−3x−4=0，x=4 或 −1；只有 x=4 通过检验。
  2. line第 3 — Squaring can create a fake root. At x=−5​ the right side x+1 is negative, but a square root never is.平方会造出假根。x=−5​ 时右边 x+1 是负数，而平方根不会是负数。 Check both in the original: only x=5​ works.把两个都代回原方程：只有 x=5​ 成立。
  3. line第 1 — (x−2)2 is x2−4x+4, not x2+4.(x−2)2=x2−4x+4，不是 x2+4。 x+4=x2−4x+4, x2−5x=0, x=0 or 5; only x=5 checks.x+4=x2−4x+4，x2−5x=0，x=0 或 5；只有 x=5 通过检验。
