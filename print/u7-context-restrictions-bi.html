Domain & range limits in context实际问题中的定义域与值域

Thinking map — keep it next to you while you work思路图——做题时放在手边

🧭 Five questions before you write动笔前的五个问题

  1. 🔎 Given已知 What does the input stand for (time, a width, a number of price increases)? Write its limits first: time starts at 0 and stops when the object lands, every length is more than 0, counts are whole numbers.输入量代表什么（时间、宽度、涨价次数）？先写出它的限制：时间从 0 开始、落地就停；每条长度都大于 0；个数只能是整数。
  2. 🎯 Asked求什么 The domain, the range, or a window ("at least", "higher than")? Answer as an inequality with units.求定义域、值域，还是一个时间段（「至少」「高于」）？用带单位的不等式作答。
  3. ✏️ Picture it画出来 Sketch only the part of the arch that is real: the start point, the vertex and the end point. For a window, draw the horizontal line y= target.只画拱形中真实存在的那一段：起点、顶点、终点。求时间段时，再画一条水平线 y= 目标值。
  4. 🧰 Tool用什么工具 Domain: solve "h=0" or "each length >0". Range: the vertex value and the values at the ends of the domain. Window: move everything to one side, factor, use a sign chart (flip the sign if you divide by a negative).定义域：解「h=0」或「每条长度 >0」。值域：顶点值和定义域两端的值。时间段：移到一边、分解、列符号表（除以负数要变号）。
  5. ✅ Check检验 Every answer must sit inside the domain. Test one value from your answer in the original model.每个答案都要落在定义域里。从答案里取一个值，代回原模型检验。

⭐ Must know必须记住

  • Domain in context: time from 0 to landing, lengths >0, counts are whole numbers.情境中的定义域：时间从 0 到落地，长度 >0，个数取整数。
  • Range in context: the vertex value (if inside the domain) and the endpoint values.情境中的值域：顶点值（若在定义域内）和端点值。
  • "At least / more than" → solve the inequality, then cut it to the domain.「至少／超过」→ 解不等式，再截到定义域内。
h(t)≥0  and  t≥0

Key (fold this part back)答案（可以折起来）
  1. line第 2 — The formula works for any x, but a rectangle does not: a width of −3 or 12 m makes a side negative.公式对任何 x 都能算，可长方形不行：宽为 −3 或 12 米时，总有一条边是负的。 Width x>0 and length 10−x>0: domain 0<x<10. Vertex x=5 gives A=25, so the range is 0<A≤25 m².宽 x>0，长 10−x>0：定义域 0<x<10。顶点 x=5 时 A=25，值域 0<A≤25 m²。
  2. line第 3 — The algebra is right, but the ball does not exist before it is thrown. t=−1 is a zero of the formula, not a moment in the story.代数没错，但球在抛出之前并不存在。t=−1 只是公式的零点，不是故事里的时刻。 Reject t=−1. Domain: 0≤t≤4 s.舍去 t=−1。定义域：0≤t≤4 秒。
  3. line第 2 — An arch is highest in the middle, not at an end. The vertex was never checked.拱形最高点在中间，不在两端。顶点根本没算。 Vertex t=2: h(2)=−20+40+25=45. Range: 0≤h≤45.顶点 t=2：h(2)=−20+40+25=45。值域：0≤h≤45。
  4. line第 2 — The ball does not stop at roof height. It falls past the roof all the way to the ground.球不会停在屋顶高度，它会越过屋顶一直落到地面。 h=0 when t2−2t−8=0, so t=4. The lowest height is 0, so the range is 0≤h≤45 m.t2−2t−8=0 时 h=0，即 t=4。最低高度是 0，所以值域是 0≤h≤45 米。
  5. line第 2 — Dividing both sides by a negative number reverses the inequality. The answer "t<1 or t>5" also says the ball is highest at the start and the end, which is backwards.两边同除以负数，不等号要反向。「t<1 或 t>5」等于说球在开头和结尾最高，正好反了。 t2−6t+5<0, so 1<t<5. This is inside the domain 0≤t≤6: above 25 m for 4 s.t2−6t+5<0，所以 1<t<5。它在定义域 0≤t≤6 内：高于 25 m 的时间共 4 秒。
