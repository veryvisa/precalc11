Simplifying & ordering radicals根式化简与比较大小

Formulas公式
ab​=a​b​(a,b≥0) — Product rule for radicals根式乘法法则
kna​=nkna​ — Mixed ↔ entire radical最简根式与整根式互化
Remember记住
  • Pull out the LARGEST perfect square (perfect cube for 3 ​): 72​=62​.提出最大的完全平方因数（立方根提完全立方数）：72​=62​。
  • Mixed → entire: square the outside number and multiply it in: 35​=45​.最简根式化为整根式：把外面的数平方后乘进去：35​=45​。
Watch out当心
  • 72​=218​ is not finished → 62​.72​=218​ 没化完 → 62​。
  • 9+16​=3+4 ✗ → 25​=5. Roots split over ×, never over +.9+16​=3+4 ✗ → 25​=5。根号只能对乘法拆，不能对加法拆。

Operations with radicals根式的四则运算

Formulas公式
mna​⋅knb​=mknab​ — Multiplying radicals (same index)同次根式相乘
(a​+b​)(a​−b​)=a−b — Conjugates multiply to a rational number共轭式相乘得有理数
Remember记住
  • Add/subtract LIKE radicals only — simplify each first: 12​+27​=53​.只有同类根式才能加减——先逐个化简：12​+27​=53​。
  • Multiply outside × outside, inside × inside; expand brackets like FOIL.相乘：系数乘系数，根号里乘根号里；括号像多项式一样展开。
Watch out当心
  • 2​+3​=5​ ✗ → unlike radicals stay as they are.2​+3​=5​ ✗ → 不同类根式不能合并。
  • (3−2​)2=9+2 ✗ → 9−62​+2=11−62​.(3−2​)2=9+2 ✗ → 9−62​+2=11−62​。

Radical equations & extraneous roots根式方程与增根

Formulas公式
A​=B ⇒ A=B2,valid only if B≥0 — Squaring step and the hidden condition平方这一步及隐含条件
Remember记住
  • Restrictions → ISOLATE the radical → raise to the index → solve → CHECK in the original.写限制条件 → 孤立根式 → 两边乘方 → 解方程 → 代回原方程检验。
  • Squaring can create extraneous roots: reject any root that fails the original.平方可能产生增根：不满足原方程的根要舍去。
Watch out当心
  • Squaring before isolating: (x​+1)2=x+1 ✗ → x+2x​+1.没孤立就平方：(x​+1)2=x+1 ✗ → x+2x​+1。
  • (2x+4​)2=2(x+4) ✗ → 4(x+4).(2x+4​)2=2(x+4) ✗ → 4(x+4)。
