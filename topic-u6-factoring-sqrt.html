📌 Key points要点

⭐ Must know必须记住
  • Zero product: get 0 on one side FIRST, then set each factor =0.零积法则：先让一边等于 0，再令每个因式 =0。
  • (…)2=k: take ±k​; k<0 → no real solution.(…)2=k：开方取 ±k​；k<0 → 无实数解。
  • Never divide by x: factor it out, or the root x=0 is lost.不要两边除以 x：把 x 提出来，否则丢掉根 x=0。

💡 If two numbers multiply to zero, one of them must be zero. That single fact solves most quadratic equations on your test in two lines.两个数相乘等于零，其中至少一个是零。就凭这一条，考卷上大多数一元二次方程两行就能解完。

  1. Factoring method: get 0 on one side, factor, then set each factor equal to 0 (zero product property).因式分解法：先让一边为 0，再分解，然后令每个因式等于 0（零积性质）。
  2. Square root method: when the equation is "something squared = number", isolate the square and take ± ​. Forgetting ± loses half the answers.直接开平方法：方程是「某式的平方 = 数」时，先把平方项单独放一边，再开方取 ±。忘了 ± 就丢掉一半答案。
  3. If the squared thing equals a negative number, there is no real solution. Never divide both sides by x — you lose the root x=0.若平方等于负数，则无实数解。不要两边同除以 x，否则会丢掉 x=0 这个根。

Before anything else, look for a ready-made square — (x−3)2=18 takes one step with square roots but four if you expand. If b2−4ac is a perfect square, it factors.先看有没有现成的平方——(x−3)2=18 开平方一步就完，展开要四步。若 b2−4ac 是完全平方数，就一定能分解。

🧭 How to get started怎么入手

Ask yourself these five, in order, before writing anything. Every worked example on this page is labelled with them.动笔之前，按顺序问自己这五个问题。本页每道例题的步骤都标了它们。

  1. 🔎 Given已知
    Is one side already 0? Is there a ready-made square like (x−3)2? Is there a common factor, such as an x in every term?有没有一边已经是 0？有没有现成的平方，比如 (x−3)2？每一项有没有公因式，比如都带 x？
  2. 🎯 Asked求什么
    Every x that makes the equation true. A quadratic can have two, one or no real answers.让方程成立的所有 x。二次方程可能有两个、一个或没有实数解。
  3. ✏️ Picture it画出来
    The answers are where y= left side meets y= right side. With 0 on one side, they are the x-intercepts of the parabola.答案就是 y=左边与 y=右边的交点。一边是 0 时，答案就是抛物线的 x 截距。
  4. 🧰 Tool用什么工具
    Ready-made square: isolate it and take ± ​. Otherwise move everything to one side, factor, and set each factor to 0.有现成的平方：先把它单独留下，再开方取 ±。否则把所有项移到一边，分解，再令每个因式等于 0。
  5. ✅ Check检验
    Put each answer back into the ORIGINAL equation. Two answers from ± should be equally far from the centre number.把每个答案代回「原」方程。± 得到的两个答案，到中间那个数的距离应该相等。
